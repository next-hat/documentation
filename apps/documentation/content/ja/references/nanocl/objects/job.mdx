# ジョブ

Nanocl の `Job` は、実行するコマンドの一覧です。<br />
[Cargo](/ja/references/nanocl/objects/cargo) と異なり、実行を終了することを目的とします。<br />

`job` を作成するときに使う `JobPartial` の OpenAPI 仕様は次のとおりです。
