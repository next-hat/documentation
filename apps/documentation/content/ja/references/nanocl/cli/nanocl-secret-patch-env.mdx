# シークレットの環境変数シークレットを更新

# 名前

env - 環境変数シークレットの値を更新します

## 書式 [#synopsis]

**env** \[**-h**\|**--help**\] \<*VALUES*\>

## 説明 [#description]

環境変数シークレットの値を更新します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

\<*VALUES*\>  
\`key=value\` 形式の値の一覧
