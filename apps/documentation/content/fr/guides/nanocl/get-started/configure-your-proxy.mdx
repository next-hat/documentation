# Configurer votre proxy

Créez des `proxy rules` avec le `proxy controller` pour exposer votre Cargo.<br/>
Une `proxy rule` redirige une adresse IP et un port, ou un domaine, vers une cible en amont d’un Cargo.


## Ajouter des règles de proxy [#add-proxy-rules]

<Callout type="info">

Pour suivre ce tutoriel, un Cargo nommé my-cargo doit fonctionner avec le port HTTP **9001** ouvert.

</Callout>

Créez `proxy.deploy-example.yml` et copiez le contenu suivant :

<StatefileBlock example="get-started/proxy" />

Créons maintenant la règle de proxy avec :

```sh
nanocl state apply -s proxy.deploy-example.yml
```

Affichez les ressources existantes avec :

```sh
nanocl resource ls
```

Testons le bon fonctionnement de notre règle :

```sh
curl --header "Host: deploy-example.com" 127.0.0.1
```
