# Ncproxy

# 名前

ncproxy

## 書式 [#synopsis]

**ncproxy** \[**--nginx-dir**\] \<**--state-dir**\>
\[**-h**\|**--help**\]

## 説明 [#description]

## オプション [#options]

**--nginx-dir**=*NGINX_DIR* \[デフォルト: /etc/nginx\]  
nginx の設定ディレクトリのパス

**--state-dir**=*STATE_DIR*  
状態ディレクトリのパス

**-h**, **--help**  
ヘルプを表示します
