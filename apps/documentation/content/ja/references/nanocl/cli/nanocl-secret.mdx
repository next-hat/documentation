# シークレット

# 名前

secret - シークレットを管理します

## 書式 [#synopsis]

**secret** \[**-h**\|**--help**\] \<*subcommands*\>

## 説明 [#description]

シークレットを管理します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

# サブコマンド

secret-remove(1)  
既存のシークレットを削除します

secret-list(1)  
既存のシークレットを一覧表示します

secret-inspect(1)  
シークレットの詳細を表示します

secret-create(1)  
新しいシークレットを作成します

secret-patch(1)  
シークレットのデータを更新します

secret-help(1)  
このメッセージ、または指定したサブコマンドのヘルプを表示します
