# Установка Nanocl

Обзор установки Nanocl.<br/>

## Предварительные требования [#prerequisites]

Компоненты Nanocl работают в контейнерах, поэтому нужен контейнерный движок.<br/>
Nanocl официально поддерживает [Docker][docker] и также работает с [Podman][podman].

### Docker [#docker]

Следуйте [официальному руководству Docker][docker_install] для своей системы.<br/>
В Windows и macOS используйте [Docker Desktop][docker_desktop].

### Podman [#podman]

Podman предоставляет Docker-совместимый API, поэтому Nanocl может работать и с ним.<br/>
Установите Podman по [официальной документации][podman_install], если предпочитаете его.

## Поддерживаемые платформы [#supported-platforms]

Готовые бинарные файлы только CLI ([nanocl][nanocl]) поставляются для следующих платформ:<br/>

- Linux: amd64
- macOS: aarch64 (Apple Silicon)
- Windows: amd64

Для других платформ и архитектур доступна установка из исходного кода через [crates.io][crates.io]. Перед запуском Cargo изучите требования на этой странице.

## Каналы выпуска [#release-channels]

Nanocl предлагает два канала обновлений: **stable** и **nightly**.

* **Stable**: последние общедоступные выпуски.
* **Nightly**: предварительные сборки для проверки будущих возможностей.

<Callout type="warning" emoji="⚠️">

Nightly-сборки экспериментальны и могут содержать несовместимые изменения.

</Callout>
