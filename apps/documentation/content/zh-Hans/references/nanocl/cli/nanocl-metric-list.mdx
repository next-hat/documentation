# 指标 列表

# 名称

list - 列出现有指标

## 语法 [#synopsis]

**list** \[**-q**\|**--quiet**\] \[**-l**\|**--limit**\]
\[**-o**\|**--offset**\] \[**--filters**\] \[**-h**\|**--help**\]

## 说明 [#description]

列出现有指标

## 选项 [#options]

**-q**, **--quiet**  
仅显示键

**-l**, **--limit** *\<LIMIT\>*  
限制结果数量，默认为 100

**-o**, **--offset** *\<OFFSET\>*  
设置结果偏移量，浏览不同结果

**--filters** *\<FILTERS\>*  
Filters

**-h**, **--help**  
显示帮助
