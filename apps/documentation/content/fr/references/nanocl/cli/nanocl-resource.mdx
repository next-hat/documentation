# Ressources

# NOM

resource - Gérer les ressources

## SYNOPSIS [#synopsis]

**resource** \[**-h**\|**--help**\] \<*subcommands*\>

## DESCRIPTION [#description]

Gérer les ressources

## OPTIONS [#options]

**-h**, **--help**  
Afficher l’aide

# SOUS-COMMANDES

resource-remove(1)  
Supprimer une ressource existante

resource-list(1)  
Lister les espaces de noms existants

resource-inspect(1)  
Inspecter une ressource

resource-history(1)  
Consulter l’historique d’une ressource

resource-revert(1)  
Restaurer une ressource à une entrée précise de l’historique

resource-help(1)  
Afficher ce message ou l’aide des sous-commandes indiquées
