# Inspecter une ressource

# NOM

inspect - Inspecter une ressource

## SYNOPSIS [#synopsis]

**inspect** \[**--display**\] \[**-h**\|**--help**\] \<*KEY*\>

## DESCRIPTION [#description]

Inspecter une ressource

## OPTIONS [#options]

**--display** *\<DISPLAY\>*  
Format d’affichage  

  
\[*valeurs possibles : *yaml, toml, json\]

**-h**, **--help**  
Afficher l’aide

\<*KEY*\>  
Clé ou nom de l’objet à inspecter
