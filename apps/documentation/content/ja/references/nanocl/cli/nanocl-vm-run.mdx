# 仮想マシンの実行

# 名前

run - 仮想マシンを実行します

## 書式 [#synopsis]

**run** \[**-n**\|**--namespace**\] \[**--hostname**\] \[**--cpu**\] \[**--mem**\]
\[**--net-iface**\] \[**--user**\] \[**--password**\] \[**--ssh-key**\]
\[**--img-size**\] \[**--kvm**\] \[**-a**\|**--attach**\]
\[**-h**\|**--help**\] \<*NAME*\> \<*IMAGE*\>

## 説明 [#description]

仮想マシンを実行します

## オプション [#options]

**-n**, **--namespace** *\<NAMESPACE\>*
新しい仮想マシンの名前空間。デフォルトは global です

**--hostname** *\<HOSTNAME\>*
仮想マシンのホスト名

**--cpu** *\<CPU\>*
仮想マシンの CPU 数。デフォルトは 1 です

**--mem** *\<MEMORY\>*
仮想マシンのメモリー容量（MB）。デフォルトは 512 です

**--net-iface** *\<NET_IFACE\>*
仮想マシンのネットワークインターフェース

**--user** *\<USER\>*
仮想マシンのデフォルトのユーザー

**--password** *\<PASSWORD\>*
仮想マシンのデフォルトのパスワード

**--ssh-key** *\<SSH_KEY\>*
ユーザーの SSH キー

**--img-size** *\<IMAGE_SIZE\>*
ディスク容量（GB）

**--kvm**
KVM を有効にします

**-a**, **--attach**
仮想マシンに接続します

**-h**, **--help**
ヘルプを表示します

\<*NAME*\>
仮想マシンの名前

\<*IMAGE*\>
仮想マシンのイメージの絶対パス
