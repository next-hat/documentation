# localhost から VPS へ

## はじめに [#introduction]

アプリケーションを VPS やベアメタル・専用サーバーにデプロイしたいのに、Nginx の設定に苦労していませんか？同じ悩みを持つ人は多く、最近の Stack Overflow でも、アプリケーションのデプロイに向けた Nginx の設定はよく質問される話題です。適切な手順があれば、この作業を分かりやすく進められます。

この詳しいガイドでは、Docker コンテナと Nginx を使って、フロントエンドアプリと API を VPS にデプロイする手順を順番に説明します。コンテナの作成と設定、基本的な Docker ネットワークの構築、ドメインからコンテナにトラフィックを転送する Nginx の設定を学びます。さらに、Certbot の無料 SSL 証明書で構成を保護する方法も説明します。

Docker と Nginx を初めて使う方にも、経験のある方にも、堅牢で安全なアプリケーション基盤を構築するための知識と手段を提供します。それでは始めましょう。


## アーキテクチャ [#architecture]

このガイドでは、`frontend` と `backend` の 2 つのサービスを作成し、次の構成でデプロイします。

<img src="/img/simple_architecture.jpg" />

手順を進めるには、ドメイン名を購入し、サーバーを指す A レコードを追加しておく必要があります。

この構成でサービスをデプロイすることで、性能、拡張性、信頼性を確保できます。フロントエンドはユーザーのリクエストを受け付け、バックエンドと通信します。バックエンドはデータを処理し、結果をフロントエンドに返します。役割を分離することで、各サービスの開発と保守が容易になり、アプリケーション全体の性能と応答性も改善できます。
