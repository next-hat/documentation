# Statistiques Cargo

# NOM

stats - Afficher les statistiques du Cargo

## SYNOPSIS [#synopsis]

**stats** \[**--no-stream**\] \[**-h**\|**--help**\] \[*KEYS*\]

## DESCRIPTION [#description]

Afficher les statistiques du Cargo

## OPTIONS [#options]

**--no-stream**  
Désactiver le flux de statistiques et récupérer uniquement le premier résultat

**-h**, **--help**  
Afficher l’aide

\[*KEYS*\]
Clés canoniques des Cargoes dont afficher les statistiques
