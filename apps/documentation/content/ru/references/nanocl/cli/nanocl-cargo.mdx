# Cargo

# НАЗВАНИЕ

cargo - Управлять Cargo

## СИНТАКСИС [#synopsis]

**cargo** \[**-h**\|**--help**\] \<*subcommands*\>

## ОПИСАНИЕ [#description]

Управлять Cargo

## ПАРАМЕТРЫ [#options]

**-h**, **--help**  
Показать справку
