# Задания

# НАЗВАНИЕ

job - Управлять заданиями

## СИНТАКСИС [#synopsis]

**job** \[**-h**\|**--help**\] \<*subcommands*\>

## ОПИСАНИЕ [#description]

Управлять заданиями

## ПАРАМЕТРЫ [#options]

**-h**, **--help**  
Показать справку

# ПОДКОМАНДЫ

job-list(1)  
Показать существующие задания

job-remove(1)  
Удалить задание по имени

job-inspect(1)  
Просмотреть задание по имени

job-logs(1)  
Показать журналы задания

job-wait(1)  
Дождаться завершения задания

job-start(1)  
Запустить задание

job-help(1)  
Показать это сообщение или справку указанных подкоманд
