# Cargo history

# NAME

history - List cargo history

## SYNOPSIS

**history** \[**-h**\|**--help**\] \<*KEY*\>

## DESCRIPTION

List cargo history

## OPTIONS

**-h**, **--help**  
Print help

\<*KEY*\>
Canonical key of the cargo whose history to browse
