# Настройка прокси

Создайте `proxy rules` через `proxy controller`, чтобы опубликовать Cargo.<br/>
Правило прокси направляет определённый IP-адрес, порт или доменное имя к upstream Cargo.


## Добавление правил прокси [#add-proxy-rules]

<Callout type="info">

Для продолжения нужен работающий Cargo my-cargo с HTTP на порту **9001**.

</Callout>

Создайте `proxy.deploy-example.yml` и скопируйте содержимое:

<StatefileBlock example="get-started/proxy" />

Создайте правило прокси командой:

```sh
nanocl state apply -s proxy.deploy-example.yml
```

Посмотрите существующие ресурсы:

```sh
nanocl resource ls
```

Проверим работу правила прокси:

```sh
curl --header "Host: deploy-example.com" 127.0.0.1
```
