# Откат ресурса

# НАЗВАНИЕ

revert - Вернуть ресурс к выбранному состоянию истории

## СИНТАКСИС [#synopsis]

**revert** \[**-h**\|**--help**\] \<*NAME*\> \<*KEY*\>

## ОПИСАНИЕ [#description]

Вернуть ресурс к выбранному состоянию истории

## ПАРАМЕТРЫ [#options]

**-h**, **--help**  
Показать справку

\<*NAME*\>  
Имя ресурса для отката

\<*KEY*\>  
Ключ состояния истории для отката
