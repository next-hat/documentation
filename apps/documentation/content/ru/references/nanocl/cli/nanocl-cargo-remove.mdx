# Удаление Cargo

# НАЗВАНИЕ

remove - Удалить Cargo по каноническим ключам

## СИНТАКСИС [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-f**\|**--force**\]
\[**-h**\|**--help**\] \[*KEYS*\]

## ОПИСАНИЕ [#description]

Удалить Cargo по каноническим ключам

## ПАРАМЕТРЫ [#options]

**-y**, **--skip-confirm**  

**-f**, **--force**  

**-h**, **--help**  
Показать справку

\[*KEYS*\]  
Ключи или имена удаляемых объектов
