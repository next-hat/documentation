# Lister les tâches

# NOM

list - Lister les tâches existantes

## SYNOPSIS [#synopsis]

**list** \[**-q**\|**--quiet**\] \[**-l**\|**--limit**\]
\[**-o**\|**--offset**\] \[**--filters**\] \[**-h**\|**--help**\]

## DESCRIPTION [#description]

Lister les tâches existantes

## OPTIONS [#options]

**-q**, **--quiet**  
Afficher uniquement les clés

**-l**, **--limit** *\<LIMIT\>*  
Limiter le nombre de résultats, 100 par défaut

**-o**, **--offset** *\<OFFSET\>*  
Décaler les résultats pour parcourir la liste

**--filters** *\<FILTERS\>*  
Filtres

**-h**, **--help**  
Afficher l’aide
