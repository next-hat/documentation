# Cargo 运行

# 名称

run - 运行 Cargo

## 语法 [#synopsis]

**run** \[**-n**\|**--namespace**\] \[**-v**\|**--volume**\] \[**-e**\|**--env**\]
\[**-h**\|**--help**\] \<*NAME*\> \<*IMAGE*\> \[*COMMAND*\]

## 说明 [#description]

运行 Cargo

## 选项 [#options]

**-n**, **--namespace** *\<NAMESPACE\>*
新 Cargo 的命名空间，默认为 global

**-v**, **--volume** *\<VOLUMES\>*  
Cargo 的卷

**-e**, **--env** *\<ENV\>*  
Cargo 的环境变量

**-h**, **--help**  
显示帮助

\<*NAME*\>  
Cargo 名称

\<*IMAGE*\>  
Cargo 镜像

\[*COMMAND*\]  
要执行的命令
