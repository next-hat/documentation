# Cargo

В Nanocl 0.18 `Cargo` — сохраняемая нагрузка с именованными приложениями `Containers`, необязательными упорядоченными `InitContainers` и целым числом `Replicas`. Сеть и порты Cargo описывают общую сетевую границу каждой реплики; конфигурация Docker и секреты контейнеров остаются у каждого именованного контейнера.

Схема OpenAPI ниже — справочник `CargoSpec`. Топология выполнения и примеры описаны в [Cargo с несколькими контейнерами](/ru/guides/nanocl/advanced-usage/multi-container-cargoes).
