# Виртуальная машина

В Nanocl `Virtual Machine` обозначает конфигурацию виртуальной машины.<br />
После создания система обеспечивает постоянную работу VM.<br />
Спецификация OpenAPI `VmSpecPartial` для создания виртуальной машины:
