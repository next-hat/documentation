# Attendre une tâche

# NOM

wait - Attendre la fin d’une tâche

## SYNOPSIS [#synopsis]

**wait** \[**-c **\] \[**-h**\|**--help**\] \<*NAME*\>

## DESCRIPTION [#description]

Attendre la fin d’une tâche

## OPTIONS [#options]

**-c** *\<CONDITION\>*  
État à attendre

**-h**, **--help**  
Afficher l’aide

\<*NAME*\>  
Nom de la tâche à attendre
