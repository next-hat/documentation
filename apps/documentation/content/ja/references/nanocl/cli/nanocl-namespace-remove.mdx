# 名前空間の削除

# 名前

remove - 名前空間を削除します

## 書式 [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-h**\|**--help**\]
\[*KEYS*\]

## 説明 [#description]

名前空間を削除します

## オプション [#options]

**-y**, **--skip-confirm**  

**-h**, **--help**  
ヘルプを表示します

\[*KEYS*\]  
削除するオブジェクトのキーまたは名前
