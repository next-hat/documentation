# コンテキスト

# 名前

context - コンテキストを管理します

## 書式 [#synopsis]

**context** \[**-h**\|**--help**\] \<*subcommands*\>

## 説明 [#description]

コンテキストを管理します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

# サブコマンド

context-list(1)  
コンテキストを一覧表示します

context-use(1)  
現在のコンテキストを設定します

context-from(1)  
ファイルから新しいコンテキストを作成します

context-help(1)  
このメッセージ、または指定したサブコマンドのヘルプを表示します
