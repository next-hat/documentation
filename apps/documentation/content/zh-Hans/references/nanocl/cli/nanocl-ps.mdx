# 进程

# 名称

ps - 显示进程

## 语法 [#synopsis]

**ps** \[**-q**\|**--quiet**\] \[**-l**\|**--limit**\]
\[**-o**\|**--offset**\] \[**--filters**\] \[**-n**\|**--namespace**\]
\[**-k**\|**--kind**\] \[**-a**\|**--all**\] \[**-h**\|**--help**\]

## 说明 [#description]

显示进程

## 选项 [#options]

**-q**, **--quiet**  
仅显示键

**-l**, **--limit** *\<LIMIT\>*  
限制结果数量，默认为 100

**-o**, **--offset** *\<OFFSET\>*  
设置结果偏移量，浏览不同结果

**--filters** *\<FILTERS\>*  
Filters

**-n**, **--namespace** *\<NAMESPACE\>*  
显示指定命名空间的全部进程

**-k**, **--kind** *\<KIND\>*  
显示指定类型的全部进程

**-a**, **--all**  

**-h**, **--help**  
显示帮助
