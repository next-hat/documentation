# リソース

# 名前

resource - リソースを管理します

## 書式 [#synopsis]

**resource** \[**-h**\|**--help**\] \<*subcommands*\>

## 説明 [#description]

リソースを管理します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

# サブコマンド

resource-remove(1)  
既存のリソースを削除します

resource-list(1)  
既存の名前空間を一覧表示します

resource-inspect(1)  
リソースの詳細を表示します

resource-history(1)  
リソースの履歴を参照します

resource-revert(1)  
リソースを指定した履歴に戻します

resource-help(1)  
このメッセージ、または指定したサブコマンドのヘルプを表示します
