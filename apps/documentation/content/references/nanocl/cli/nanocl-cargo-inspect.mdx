# Cargo inspect

# NAME

inspect - Inspect a cargo by its canonical key

## SYNOPSIS

**inspect** \[**--display**\] \[**-h**\|**--help**\] \<*KEY*\>

## DESCRIPTION

Inspect a cargo by its canonical key

## OPTIONS

**--display** *\<DISPLAY\>*  
Display format  

  
\[*possible values: *yaml, toml, json\]

**-h**, **--help**  
Print help

\<*KEY*\>  
Canonical key of the object to inspect
