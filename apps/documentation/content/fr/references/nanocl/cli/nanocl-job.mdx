# Tâches

# NOM

job - Gérer les tâches

## SYNOPSIS [#synopsis]

**job** \[**-h**\|**--help**\] \<*subcommands*\>

## DESCRIPTION [#description]

Gérer les tâches

## OPTIONS [#options]

**-h**, **--help**  
Afficher l’aide

# SOUS-COMMANDES

job-list(1)  
Lister les tâches existantes

job-remove(1)  
Supprimer une tâche par son nom

job-inspect(1)  
Inspecter une tâche par son nom

job-logs(1)  
Afficher les journaux d’une tâche

job-wait(1)  
Attendre la fin d’une tâche

job-start(1)  
Démarrer une tâche

job-help(1)  
Afficher ce message ou l’aide des sous-commandes indiquées
