# Modifier un secret d’environnement

# NOM

env - Mettre à jour les valeurs du secret d’environnement

## SYNOPSIS [#synopsis]

**env** \[**-h**\|**--help**\] \<*VALUES*\>

## DESCRIPTION [#description]

Mettre à jour les valeurs du secret d’environnement

## OPTIONS [#options]

**-h**, **--help**  
Afficher l’aide

\<*VALUES*\>  
Liste de valeurs au format \`key=value\`
