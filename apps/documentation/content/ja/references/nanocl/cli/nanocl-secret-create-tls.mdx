# シークレットのTLS シークレットを作成

# 名前

tls - 新しい nanocl.io/tls シークレットを作成します

## 書式 [#synopsis]

**tls** \[**--certificate**\] \[**--certificate-path**\]
\[**--certificate-key**\] \[**--certificate-key-path**\]
\[**--certificate-client**\] \[**--certificate-client-path**\]
\[**--dhparam**\] \[**--verify-client**\] \[**-h**\|**--help**\]

## 説明 [#description]

新しい nanocl.io/tls シークレットを作成します

## オプション [#options]

**--certificate** *\<CERTIFICATE\>*  
証明書

**--certificate-path** *\<CERTIFICATE_PATH\>*  
ファイルから読み込む証明書のパス

**--certificate-key** *\<CERTIFICATE_KEY\>*  
証明書の秘密鍵

**--certificate-key-path** *\<CERTIFICATE_KEY_PATH\>*  
ファイルから読み込む証明書の秘密鍵のパス

**--certificate-client** *\<CERTIFICATE_CLIENT\>*  
クライアント証明書

**--certificate-client-path** *\<CERTIFICATE_CLIENT_PATH\>*  
ファイルから読み込むクライアント証明書のパス

**--dhparam** *\<DHPARAM\>*  
DH パラメーター

**--verify-client**  
クライアントを検証します

**-h**, **--help**  
ヘルプを表示します
