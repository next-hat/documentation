# Sous-états

Vous pouvez inclure d’autres Statefiles dans le vôtre avec la clé `SubStates`.

C’est utile pour réutiliser un Statefile à plusieurs endroits.<br />
Ou, dans un monorepo, pour disposer d’une seule source de vérité pour votre état.
