# Создание секрета

# НАЗВАНИЕ

create - Создать секрет

## СИНТАКСИС [#synopsis]

**create** \[**-h**\|**--help**\] \<*NAME*\> \<*subcommands*\>

## ОПИСАНИЕ [#description]

Создать секрет

## ПАРАМЕТРЫ [#options]

**-h**, **--help**  
Показать справку

\<*NAME*\>  
Имя секрета
