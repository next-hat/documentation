# シークレットの環境変数シークレットを作成

# 名前

env - 新しい nanocl.io/env シークレットを作成します

## 書式 [#synopsis]

**env** \[**-h**\|**--help**\] \<*VALUES*\>

## 説明 [#description]

新しい nanocl.io/env シークレットを作成します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

\<*VALUES*\>  
\`key=value\` 形式の値の一覧
