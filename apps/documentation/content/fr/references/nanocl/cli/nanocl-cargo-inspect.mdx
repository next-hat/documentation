# Inspecter un Cargo

# NOM

inspect - Inspecter un Cargo par sa clé canonique

## SYNOPSIS [#synopsis]

**inspect** \[**--display**\] \[**-h**\|**--help**\] \<*KEY*\>

## DESCRIPTION [#description]

Inspecter un Cargo par sa clé canonique

## OPTIONS [#options]

**--display** *\<DISPLAY\>*  
Format d’affichage  

  
\[*valeurs possibles : *yaml, toml, json\]

**-h**, **--help**  
Afficher l’aide

\<*KEY*\>  
Clé canonique de l’objet à inspecter
