# Выполнение

# НАЗВАНИЕ

exec - Выполнить команду в процессе

## СИНТАКСИС [#synopsis]

**exec** \[**-d**\|**--detach**\] \[**--detach-keys**\]
\[**-e**\|**--env**\] \[**--env-file**\]
\[**-i**\|**--interactive**\] \[**--privileged**\]
\[**-t**\|**--tty**\] \[**-u**\|**--user**\]
\[**-w**\|**--workdir**\] \[**-h**\|**--help**\]
\<*PROCESS*\> \<*COMMAND*\>...

## ОПИСАНИЕ [#description]

Выполнить команду в процессе

## ПАРАМЕТРЫ [#options]

**-d**, **--detach**  
Выполнить команду в фоне

**--detach-keys** *\<DETACH_KEYS\>*  
Переопределить сочетание клавиш для отсоединения от интерактивного exec

**-e**, **--env** *\<ENV\>*  
Задать переменную окружения

**--env-file** *\<ENV_FILE\>*  
Прочитать переменные окружения из файла

**-i**, **--interactive**  
Сохранить стандартный ввод открытым

**--privileged**  
Предоставить команде расширенные права

**-t**, **--tty**  
Allocate a pseudo-TTY

**-u**, **--user** *\<USER\>*  
Пользователь и необязательная группа команды

**-w**, **--workdir** *\<WORKDIR\>*  
Рабочий каталог внутри процесса

**-h**, **--help**  
Показать справку

*\<PROCESS\>*  
Конкретное имя процесса или полный Docker ID

*\<COMMAND\>*...  
Выполняемая команда и аргументы
