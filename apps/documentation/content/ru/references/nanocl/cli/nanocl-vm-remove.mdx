# Удаление VM

# НАЗВАНИЕ

remove - Удалить VM по каноническим ключам

## СИНТАКСИС [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-h**\|**--help**\]
\[*KEYS*\]

## ОПИСАНИЕ [#description]

Удалить VM по каноническим ключам

## ПАРАМЕТРЫ [#options]

**-y**, **--skip-confirm**  

**-h**, **--help**  
Показать справку

\[*KEYS*\]
