# Резервное копирование

# НАЗВАНИЕ

backup - Создать резервную копию текущего состояния

## СИНТАКСИС [#synopsis]

**backup** \[**-o**\|**--output-dir**\] \[**-y**\|**--yes**\]
\[**-h**\|**--help**\]

## ОПИСАНИЕ [#description]

Создать резервную копию текущего состояния

## ПАРАМЕТРЫ [#options]

**-o**, **--output-dir** *\<OUTPUT_DIR\>*  
Каталог резервной копии; по умолчанию текущий каталог

**-y**, **--yes**  
Пропустить подтверждение

**-h**, **--help**  
Показать справку
