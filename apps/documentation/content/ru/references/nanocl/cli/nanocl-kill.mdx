# Отправка сигнала

# НАЗВАНИЕ

kill - Отправить сигнал процессу

## СИНТАКСИС [#synopsis]

**kill** \[**-s**\|**--signal**\] \[**-h**\|**--help**\]
\<*PROCESS*\>

## ОПИСАНИЕ [#description]

Отправить сигнал процессу

## ПАРАМЕТРЫ [#options]

**-s**, **--signal** *\<SIGNAL\>* \[по умолчанию: SIGKILL\]  
Сигнал для отправки процессу

**-h**, **--help**  
Показать справку

*\<PROCESS\>*  
Конкретное имя процесса или полный Docker ID
