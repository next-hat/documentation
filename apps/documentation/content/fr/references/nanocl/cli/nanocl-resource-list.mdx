# Lister les ressources

# NOM

list - Lister les espaces de noms existants

## SYNOPSIS [#synopsis]

**list** \[**-q**\|**--quiet**\] \[**-l**\|**--limit**\]
\[**-o**\|**--offset**\] \[**--filters**\] \[**-h**\|**--help**\]

## DESCRIPTION [#description]

Lister les espaces de noms existants

## OPTIONS [#options]

**-q**, **--quiet**  
Afficher uniquement les clés

**-l**, **--limit** *\<LIMIT\>*  
Limiter le nombre de résultats, 100 par défaut

**-o**, **--offset** *\<OFFSET\>*  
Décaler les résultats pour parcourir la liste

**--filters** *\<FILTERS\>*  
Filtres

**-h**, **--help**  
Afficher l’aide
