# 仮想マシンの更新

# 名前

patch - 仮想マシンを更新します

## 書式 [#synopsis]

**patch** \[**--user**\] \[**--password**\] \[**--ssh-key**\]
\[**--hostname**\] \[**--cpu**\] \[**--mem**\] \[**--kvm**\]
\[**--net-iface**\] \[**-h**\|**--help**\] \<*KEY*\>

## 説明 [#description]

仮想マシンを更新します

## オプション [#options]

**--user** *\<USER\>*  
仮想マシンのデフォルトのユーザー

**--password** *\<PASSWORD\>*  
仮想マシンのデフォルトのパスワード

**--ssh-key** *\<SSH_KEY\>*  
ユーザーの SSH キー

**--hostname** *\<HOSTNAME\>*  
仮想マシンのホスト名

**--cpu** *\<CPU\>*  
仮想マシンの CPU 数。デフォルトは 1 です

**--mem** *\<MEMORY\>*  
仮想マシンのメモリー容量（MB）。デフォルトは 512 です

**--kvm**  
KVM を有効にします

**--net-iface** *\<NET_IFACE\>*  
仮想マシンのネットワークインターフェース

**-h**, **--help**  
ヘルプを表示します

\<*KEY*\>
仮想マシンの正規キー
