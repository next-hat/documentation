# НАЗВАНИЕ

inspect - Просмотреть задание по имени

## СИНТАКСИС [#synopsis]

**inspect** \[**--display**\] \[**-h**\|**--help**\] \<*KEY*\>

## ОПИСАНИЕ [#description]

Просмотреть задание по имени

## ПАРАМЕТРЫ [#options]

**--display** *\<DISPLAY\>*  
Формат вывода  

  
\[*допустимые значения: *yaml, toml, json\]

**-h**, **--help**  
Показать справку

\<*KEY*\>  
Ключ или имя просматриваемого объекта
