# Создание VM

# НАЗВАНИЕ

create - Создать VM

## СИНТАКСИС [#synopsis]

**create** \[**-n**\|**--namespace**\] \[**--hostname**\] \[**--cpu**\] \[**--mem**\]
\[**--net-iface**\] \[**--user**\] \[**--password**\] \[**--ssh-key**\]
\[**--kvm**\] \[**-h**\|**--help**\] \<*NAME*\> \<*IMAGE*\>

## ОПИСАНИЕ [#description]

Создать VM

## ПАРАМЕТРЫ [#options]

**-n**, **--namespace** *\<NAMESPACE\>*
Пространство имён новой VM; по умолчанию global

**--hostname** *\<HOSTNAME\>*
Имя хоста VM

**--cpu** *\<CPU\>*
Число CPU VM; по умолчанию 1

**--mem** *\<MEMORY\>*
Память VM в МБ; по умолчанию 512

**--net-iface** *\<NET_IFACE\>*
Сетевой интерфейс VM

**--user** *\<USER\>*
Пользователь VM по умолчанию

**--password** *\<PASSWORD\>*
Пароль VM по умолчанию

**--ssh-key** *\<SSH_KEY\>*
Ключ SSH пользователя

**--kvm**
Включить KVM

**-h**, **--help**
Показать справку

\<*NAME*\>
Имя VM

\<*IMAGE*\>
Полный путь образа VM
