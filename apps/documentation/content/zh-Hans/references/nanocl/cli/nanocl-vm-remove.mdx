# VM 移除

# 名称

remove - 按规范键移除 VM

## 语法 [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-h**\|**--help**\]
\[*KEYS*\]

## 说明 [#description]

按规范键移除 VM

## 选项 [#options]

**-y**, **--skip-confirm**  

**-h**, **--help**  
显示帮助

\[*KEYS*\]  
要移除的对象键或名称
