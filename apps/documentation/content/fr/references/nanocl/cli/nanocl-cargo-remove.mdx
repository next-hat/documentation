# Supprimer un Cargo

# NOM

remove - Supprimer des Cargoes par leurs clés canoniques

## SYNOPSIS [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-f**\|**--force**\]
\[**-h**\|**--help**\] \[*KEYS*\]

## DESCRIPTION [#description]

Supprimer des Cargoes par leurs clés canoniques

## OPTIONS [#options]

**-y**, **--skip-confirm**  

**-f**, **--force**  

**-h**, **--help**  
Afficher l’aide

\[*KEYS*\]  
Clés ou noms des objets à supprimer
