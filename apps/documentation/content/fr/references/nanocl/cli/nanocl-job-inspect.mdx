# Inspecter une tâche

# NOM

inspect - Inspecter une tâche par son nom

## SYNOPSIS [#synopsis]

**inspect** \[**--display**\] \[**-h**\|**--help**\] \<*KEY*\>

## DESCRIPTION [#description]

Inspecter une tâche par son nom

## OPTIONS [#options]

**--display** *\<DISPLAY\>*  
Format d’affichage  

  
\[*valeurs possibles : *yaml, toml, json\]

**-h**, **--help**  
Afficher l’aide

\<*KEY*\>  
Clé ou nom de l’objet à inspecter
