# Créer un Cargo

# NOM

create - Créer un Cargo

## SYNOPSIS [#synopsis]

**create** \[**-n**\|**--namespace**\] \[**-v**\|**--volume**\] \[**-e**\|**--env**\]
\[**-h**\|**--help**\] \<*NAME*\> \<*IMAGE*\>

## DESCRIPTION [#description]

Créer un Cargo

## OPTIONS [#options]

**-n**, **--namespace** *\<NAMESPACE\>*
Espace de noms du nouveau Cargo ; global par défaut

**-v**, **--volume** *\<VOLUMES\>*  
Volumes du Cargo

**-e**, **--env** *\<ENV\>*  
Variables d’environnement du Cargo

**-h**, **--help**  
Afficher l’aide

\<*NAME*\>  
Nom du Cargo

\<*IMAGE*\>  
Image du Cargo
