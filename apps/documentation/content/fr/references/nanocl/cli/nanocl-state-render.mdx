# Générer un Statefile

# NOM

render - Produire un Statefile avec ses arguments dans un fichier de sortie

## SYNOPSIS [#synopsis]

**render** \[**-s**\|**--source**\] \[**-o**\|**--output**\]
\[**-y**\|**--yes**\] \[**-h**\|**--help**\] \[*ARGS*\]

## DESCRIPTION [#description]

Produire un Statefile avec ses arguments dans un fichier de sortie

## OPTIONS [#options]

**-s**, **--source** *\<SOURCE\>*  
Chemin ou URL du Statefile

**-o**, **--output** *\<OUTPUT\>*  
Chemin de sortie du Statefile rendu

**-y**, **--yes**  
Ignorer la demande de confirmation

**-h**, **--help**  
Afficher l’aide

\[*ARGS*\]  
Arguments supplémentaires à transmettre au fichier
