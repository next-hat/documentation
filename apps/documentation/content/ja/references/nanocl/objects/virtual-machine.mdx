# 仮想マシン

Nanocl の `Virtual Machine` は仮想マシンの設定を表します。<br />
作成後は、システムが仮想マシンの稼働状態を維持します。<br />
`Virtual Machine` を作成するときに使う `VmSpecPartial` の OpenAPI 仕様は次のとおりです。
