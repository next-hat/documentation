# Контексты

# НАЗВАНИЕ

context - Управлять контекстами

## СИНТАКСИС [#synopsis]

**context** \[**-h**\|**--help**\] \<*subcommands*\>

## ОПИСАНИЕ [#description]

Управлять контекстами

## ПАРАМЕТРЫ [#options]

**-h**, **--help**  
Показать справку

# ПОДКОМАНДЫ

context-list(1)  
Показать контексты

context-use(1)  
Выбрать текущий контекст

context-from(1)  
Создать контекст из файла

context-help(1)  
Показать это сообщение или справку указанных подкоманд
