# バックアップ

# 名前

backup - 現在の状態をバックアップします

## 書式 [#synopsis]

**backup** \[**-o**\|**--output-dir**\] \[**-y**\|**--yes**\]
\[**-h**\|**--help**\]

## 説明 [#description]

現在の状態をバックアップします

## オプション [#options]

**-o**, **--output-dir** *\<OUTPUT_DIR\>*  
バックアップの保存先ディレクトリ。デフォルトは現在のディレクトリです

**-y**, **--yes**  
確認を省略します

**-h**, **--help**  
ヘルプを表示します
