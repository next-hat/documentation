# Restaurer une ressource

# NOM

revert - Restaurer une ressource à une entrée précise de l’historique

## SYNOPSIS [#synopsis]

**revert** \[**-h**\|**--help**\] \<*NAME*\> \<*KEY*\>

## DESCRIPTION [#description]

Restaurer une ressource à une entrée précise de l’historique

## OPTIONS [#options]

**-h**, **--help**  
Afficher l’aide

\<*NAME*\>  
Nom de la ressource à restaurer

\<*KEY*\>  
Clé de l’entrée d’historique à restaurer
