# Cargoのログ

# 名前

logs - ログを表示します

## 書式 [#synopsis]

**logs** \[**-s **\] \[**-u **\] \[**-t **\] \[**--timestamps**\] \[**-f
**\] \[**-h**\|**--help**\] \<*KEY*\>

## 説明 [#description]

ログを表示します

## オプション [#options]

**-s** *\<SINCE\>*  
指定した Unix タイムスタンプ以降のログだけを含めます

**-u** *\<UNTIL\>*  
指定した Unix タイムスタンプまでのログだけを含めます

**-t** *\<TAIL\>*  
整数の場合は最後の n 件のログだけを返し、"all" の場合はすべてのログを返します

**--timestamps**  
真偽値。指定すると各ログ行にタイムスタンプを付けます

**-f**  
真偽値。指定するとログをストリームとして開きます

**-h**, **--help**  
ヘルプを表示します

\<*KEY*\>
ログを表示する Cargo の正規キー
