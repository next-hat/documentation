# Изменение VM

# НАЗВАНИЕ

patch - Изменить VM

## СИНТАКСИС [#synopsis]

**patch** \[**--user**\] \[**--password**\] \[**--ssh-key**\]
\[**--hostname**\] \[**--cpu**\] \[**--mem**\] \[**--kvm**\]
\[**--net-iface**\] \[**-h**\|**--help**\] \<*KEY*\>

## ОПИСАНИЕ [#description]

Изменить VM

## ПАРАМЕТРЫ [#options]

**--user** *\<USER\>*  
Пользователь VM по умолчанию

**--password** *\<PASSWORD\>*  
Пароль VM по умолчанию

**--ssh-key** *\<SSH_KEY\>*  
Ключ SSH пользователя

**--hostname** *\<HOSTNAME\>*  
Имя хоста VM

**--cpu** *\<CPU\>*  
Число CPU VM; по умолчанию 1

**--mem** *\<MEMORY\>*  
Память VM в МБ; по умолчанию 512

**--kvm**  
Включить KVM

**--net-iface** *\<NET_IFACE\>*  
Сетевой интерфейс VM

**-h**, **--help**  
Показать справку

\<*KEY*\>
Канонический ключ VM
