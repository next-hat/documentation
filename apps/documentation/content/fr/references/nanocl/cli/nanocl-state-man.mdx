# Manuel du Statefile

# NOM

man - Afficher la documentation d’un Statefile

## SYNOPSIS [#synopsis]

**man** \<**-s**\|**--source**\> \[**-h**\|**--help**\]

## DESCRIPTION [#description]

Afficher la documentation d’un Statefile

## OPTIONS [#options]

**-s**, **--source** *\<SOURCE\>*  
Chemin ou URL du Statefile

**-h**, **--help**  
Afficher l’aide
