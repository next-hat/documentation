# 发送信号

# 名称

kill - 向进程发送信号

## 语法 [#synopsis]

**kill** \[**-s**\|**--signal**\] \[**-h**\|**--help**\]
\<*PROCESS*\>

## 说明 [#description]

向进程发送信号

## 选项 [#options]

**-s**, **--signal** *\<SIGNAL\>* \[默认值： SIGKILL\]  
要发送给进程的信号

**-h**, **--help**  
显示帮助

*\<PROCESS\>*  
具体进程名称或完整 Docker ID
