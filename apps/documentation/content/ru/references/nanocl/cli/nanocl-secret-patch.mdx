# Изменение секрета

# НАЗВАНИЕ

patch - Обновить данные секрета

## СИНТАКСИС [#synopsis]

**patch** \[**-h**\|**--help**\] \<*NAME*\> \<*subcommands*\>

## ОПИСАНИЕ [#description]

Обновить данные секрета

## ПАРАМЕТРЫ [#options]

**-h**, **--help**  
Показать справку

\<*NAME*\>  
Имя обновляемого секрета

# ПОДКОМАНДЫ

patch-env(1)  
Обновить значения секрета окружения

patch-tls(1)  
Обновить значения секрета TLS

patch-container-registry(1)  
Обновить значения секрета реестра контейнеров

patch-help(1)  
Показать это сообщение или справку указанных подкоманд
