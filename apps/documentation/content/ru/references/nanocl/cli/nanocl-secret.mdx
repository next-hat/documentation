# Секреты

# НАЗВАНИЕ

secret - Управлять секретами

## СИНТАКСИС [#synopsis]

**secret** \[**-h**\|**--help**\] \<*subcommands*\>

## ОПИСАНИЕ [#description]

Управлять секретами

## ПАРАМЕТРЫ [#options]

**-h**, **--help**  
Показать справку

# ПОДКОМАНДЫ

secret-remove(1)  
Удалить существующий секрет

secret-list(1)  
Показать существующие секреты

secret-inspect(1)  
Просмотреть секрет

secret-create(1)  
Создать секрет

secret-patch(1)  
Обновить данные секрета

secret-help(1)  
Показать это сообщение или справку указанных подкоманд
