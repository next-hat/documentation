# Удаление секрета

# НАЗВАНИЕ

remove - Удалить существующий секрет

## СИНТАКСИС [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-h**\|**--help**\]
\[*KEYS*\]

## ОПИСАНИЕ [#description]

Удалить существующий секрет

## ПАРАМЕТРЫ [#options]

**-y**, **--skip-confirm**  

**-h**, **--help**  
Показать справку

\[*KEYS*\]  
Ключи или имена удаляемых объектов
