# Lister les Cargoes

# NOM

list - Lister les Cargoes existants

## SYNOPSIS [#synopsis]

**list** \[**-n**\|**--namespace**\] \[**-q**\|**--quiet**\] \[**-l**\|**--limit**\]
\[**-o**\|**--offset**\] \[**--filters**\] \[**-h**\|**--help**\]

## DESCRIPTION [#description]

Lister les Cargoes existants

## OPTIONS [#options]

**-n**, **--namespace** *\<NAMESPACE\>*
Filtre d’espace de noms facultatif ; son absence renvoie les ressources de tous les espaces

**-q**, **--quiet**  
Afficher uniquement les clés

**-l**, **--limit** *\<LIMIT\>*  
Limiter le nombre de résultats, 100 par défaut

**-o**, **--offset** *\<OFFSET\>*  
Décaler les résultats pour parcourir la liste

**--filters** *\<FILTERS\>*  
Filtres

**-h**, **--help**  
Afficher l’aide
