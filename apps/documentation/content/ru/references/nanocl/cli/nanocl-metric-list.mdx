# Список метрик

# НАЗВАНИЕ

list - Показать существующие метрики

## СИНТАКСИС [#synopsis]

**list** \[**-q**\|**--quiet**\] \[**-l**\|**--limit**\]
\[**-o**\|**--offset**\] \[**--filters**\] \[**-h**\|**--help**\]

## ОПИСАНИЕ [#description]

Показать существующие метрики

## ПАРАМЕТРЫ [#options]

**-q**, **--quiet**  
Показывать только ключи

**-l**, **--limit** *\<LIMIT\>*  
Ограничить число результатов; по умолчанию 100

**-o**, **--offset** *\<OFFSET\>*  
Смещение для перехода между результатами

**--filters** *\<FILTERS\>*  
Filters

**-h**, **--help**  
Показать справку
