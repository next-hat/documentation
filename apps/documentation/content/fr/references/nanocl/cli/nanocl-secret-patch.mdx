# Modifier un secret

# NOM

patch - Mettre à jour les données d’un secret

## SYNOPSIS [#synopsis]

**patch** \[**-h**\|**--help**\] \<*NAME*\> \<*subcommands*\>

## DESCRIPTION [#description]

Mettre à jour les données d’un secret

## OPTIONS [#options]

**-h**, **--help**  
Afficher l’aide

\<*NAME*\>  
Nom du secret à mettre à jour

# SOUS-COMMANDES

patch-env(1)  
Mettre à jour les valeurs du secret d’environnement

patch-tls(1)  
Mettre à jour les valeurs du secret TLS

patch-container-registry(1)  
Mettre à jour les valeurs du secret de registre

patch-help(1)  
Afficher ce message ou l’aide des sous-commandes indiquées
