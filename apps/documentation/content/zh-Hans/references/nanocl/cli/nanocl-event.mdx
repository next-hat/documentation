# 事件

# 名称

event - 显示或监听事件

## 语法 [#synopsis]

**event** \[**-h**\|**--help**\] \<*subcommands*\>

## 说明 [#description]

显示或监听事件

## 选项 [#options]

**-h**, **--help**  
显示帮助

# 子命令

event-list(1)  
列出现有事件

event-watch(1)  
实时监听新事件

event-inspect(1)  
检查指定事件

event-help(1)  
显示此消息或指定子命令的帮助
