# Modifier une VM

# NOM

patch - Modifier une VM

## SYNOPSIS [#synopsis]

**patch** \[**--user**\] \[**--password**\] \[**--ssh-key**\]
\[**--hostname**\] \[**--cpu**\] \[**--mem**\] \[**--kvm**\]
\[**--net-iface**\] \[**-h**\|**--help**\] \<*KEY*\>

## DESCRIPTION [#description]

Modifier une VM

## OPTIONS [#options]

**--user** *\<USER\>*  
Utilisateur par défaut de la VM

**--password** *\<PASSWORD\>*  
Mot de passe par défaut de la VM

**--ssh-key** *\<SSH_KEY\>*  
Clé SSH de l’utilisateur

**--hostname** *\<HOSTNAME\>*  
Nom d’hôte de la VM

**--cpu** *\<CPU\>*  
Nombre de CPU de la VM, 1 par défaut

**--mem** *\<MEMORY\>*  
Mémoire de la VM en MB, 512 par défaut

**--kvm**  
Activer KVM

**--net-iface** *\<NET_IFACE\>*  
Interface réseau de la VM

**-h**, **--help**  
Afficher l’aide

\<*KEY*\>
Clé canonique de la VM
