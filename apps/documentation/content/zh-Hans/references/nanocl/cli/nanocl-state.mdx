# Statefile

# 名称

state - 应用或移除 Statefile

## 语法 [#synopsis]

**state** \[**-h**\|**--help**\] \<*subcommands*\>

## 说明 [#description]

应用或移除 Statefile

## 选项 [#options]

**-h**, **--help**  
显示帮助

# 子命令

state-man(1)  
显示 Statefile 文档

state-apply(1)  
从 Statefile 创建或更新对象

state-render(1)  
使用参数渲染 Statefile 并写入输出文件

state-logs(1)  
显示 Statefile 对象的日志

state-remove(1)  
移除 Statefile 中的对象

state-help(1)  
显示此消息或指定子命令的帮助
