# Удаление

# НАЗВАНИЕ

uninstall - Удалить компоненты

## СИНТАКСИС [#synopsis]

**uninstall** \[**--docker-host**\] \[**-t**\|**--template**\]
\[**--docker-desktop**\] \[**-h**\|**--help**\]

## ОПИСАНИЕ [#description]

Удалить компоненты

## ПАРАМЕТРЫ [#options]

**--docker-host** *\<DOCKER_HOST\>*  
Хост Docker с установленным Nanocl; по умолчанию unix:///var/run/docker.sock

**-t**, **--template** *\<TEMPLATE\>*  
Шаблон удаления Nanocl; определяется автоматически

**--docker-desktop**  
Указать Docker Desktop; определяется автоматически, если контекст Docker — desktop-linux

**-h**, **--help**  
Показать справку
