# Statefile

Statefile は、Cargo、仮想マシン、Resource、Job、Secret の望ましい状態を記述します。Nanocl 0.18 では `ApiVersion: v0.18` を使用します。Cargo には名前付きの `Containers` と、任意の `InitContainers` を設定します。
