# Процессы

# НАЗВАНИЕ

ps - Показать процессы

## СИНТАКСИС [#synopsis]

**ps** \[**-q**\|**--quiet**\] \[**-l**\|**--limit**\]
\[**-o**\|**--offset**\] \[**--filters**\] \[**-n**\|**--namespace**\]
\[**-k**\|**--kind**\] \[**-a**\|**--all**\] \[**-h**\|**--help**\]

## ОПИСАНИЕ [#description]

Показать процессы

## ПАРАМЕТРЫ [#options]

**-q**, **--quiet**  
Показывать только ключи

**-l**, **--limit** *\<LIMIT\>*  
Ограничить число результатов; по умолчанию 100

**-o**, **--offset** *\<OFFSET\>*  
Смещение для перехода между результатами

**--filters** *\<FILTERS\>*  
Filters

**-n**, **--namespace** *\<NAMESPACE\>*  
Показать все процессы указанного пространства имён

**-k**, **--kind** *\<KIND\>*  
Показать все процессы указанного вида

**-a**, **--all**  

**-h**, **--help**  
Показать справку
