# Nanocl

# 名前

nanocl - コンテナと仮想マシンのオーケストレーター

## 書式 [#synopsis]

**nanocl** \[**-H**\|**--host**\] \[**-h**\|**--help**\]
\[**-V**\|**--version**\] \<*subcommands*\>

## 説明 [#description]

Nanocl は、コンテナと仮想マシン向けのモダンで自己完結型のオーケストレーターです。宣言的な Statefile（YAML/TOML/JSON）と一貫した予測可能なデフォルト設定により、開発から本番までの流れを整えます。性能と安全性のために Rust で実装されており、運用負荷を抑えながら高い機能性と拡張性を提供します。動的ルーティング、DNS、エンドツーエンド TLS を使って Cargo、リソース、ジョブ、仮想マシンを管理できます。まずローカルの単一ノードで始め、準備が整ったら拡張できます。習得しやすく、本番運用を前提に設計されています。

## オプション [#options]

**-H**, **--host** *\<HOST\>*  
Nanocld ホストのデフォルト: unix://run/nanocl/nanocl.sock

**-h**, **--help**  
ヘルプを表示します（-h で概要を確認できます）

**-V**, **--version**  
バージョンを表示します
