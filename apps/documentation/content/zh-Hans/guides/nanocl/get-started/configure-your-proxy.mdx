# 配置代理

通过 `proxy controller` 创建 `proxy rules`，可以对外开放 Cargo。<br/>
代理规则将指定 IP 地址、端口或域名转发到 Cargo 上游。


## 添加代理规则 [#add-proxy-rules]

<Callout type="info">

继续之前，需要有名为 my-cargo 的 Cargo 在运行，并在 **9001** 端口提供 HTTP 服务。

</Callout>

创建 `proxy.deploy-example.yml` 文件，复制以下内容：

<StatefileBlock example="get-started/proxy" />

运行以下命令创建代理规则：

```sh
nanocl state apply -s proxy.deploy-example.yml
```

查看已有资源：

```sh
nanocl resource ls
```

测试代理规则是否生效：

```sh
curl --header "Host: deploy-example.com" 127.0.0.1
```

预期输出：

