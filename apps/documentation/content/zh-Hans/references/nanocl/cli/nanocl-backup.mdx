# 备份

# 名称

backup - 备份当前状态

## 语法 [#synopsis]

**backup** \[**-o**\|**--output-dir**\] \[**-y**\|**--yes**\]
\[**-h**\|**--help**\]

## 说明 [#description]

备份当前状态

## 选项 [#options]

**-o**, **--output-dir** *\<OUTPUT_DIR\>*  
备份写入目录，默认为当前目录

**-y**, **--yes**  
跳过确认

**-h**, **--help**  
显示帮助
