# メトリクス

# 名前

metric - メトリクスを管理します

## 書式 [#synopsis]

**metric** \[**-h**\|**--help**\] \<*subcommands*\>

## 説明 [#description]

メトリクスを管理します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

# サブコマンド

metric-list(1)  
既存のメトリクスを一覧表示します

metric-inspect(1)  
メトリクスの詳細を表示します

metric-help(1)  
このメッセージ、または指定したサブコマンドのヘルプを表示します
