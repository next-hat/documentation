# Журналы Cargo

# НАЗВАНИЕ

logs - Показать журналы

## СИНТАКСИС [#synopsis]

**logs** \[**-s **\] \[**-u **\] \[**-t **\] \[**--timestamps**\] \[**-f
**\] \[**-h**\|**--help**\] \<*KEY*\>

## ОПИСАНИЕ [#description]

Показать журналы

## ПАРАМЕТРЫ [#options]

**-s** *\<SINCE\>*  
Включать журналы начиная с метки времени Unix

**-u** *\<UNTIL\>*  
Включать журналы до метки времени Unix

**-t** *\<TAIL\>*  
Целое число возвращает последние n записей; "all" возвращает все записи

**--timestamps**  
Логический параметр: добавлять метку времени к каждой строке

**-f**  
Логический параметр: открыть журнал как поток

**-h**, **--help**  
Показать справку

\<*KEY*\>
Канонический ключ Cargo для просмотра журналов
