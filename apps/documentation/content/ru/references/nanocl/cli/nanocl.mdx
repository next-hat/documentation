# Nanocl

# НАЗВАНИЕ

nanocl - Оркестратор контейнеров и виртуальных машин

## СИНТАКСИС [#synopsis]

**nanocl** \[**-H**\|**--host**\] \[**-h**\|**--help**\]
\[**-V**\|**--version**\] \<*subcommands*\>

## ОПИСАНИЕ [#description]

Nanocl — современный самостоятельный оркестратор контейнеров и виртуальных машин. Декларативные Statefile (YAML/TOML/JSON) и предсказуемые значения по умолчанию обеспечивают удобный путь от разработки до эксплуатации. Rust даёт производительность и безопасность, а небольшие затраты на эксплуатацию сочетаются с мощностью и расширяемостью. Управляйте Cargo, ресурсами, заданиями и VM с динамической маршрутизацией, DNS и сквозным TLS. Начните локально на одном узле и масштабируйтесь по мере готовности — простой в изучении и пригодный для производства.

## ПАРАМЕТРЫ [#options]

**-H**, **--host** *\<HOST\>*  
Хост Nanocld по умолчанию: unix://run/nanocl/nanocl.sock

**-h**, **--help**  
Показать справку (краткая справка с -h)

**-V**, **--version**  
Показать версию
