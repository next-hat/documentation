# Создание Cargo

# НАЗВАНИЕ

create - Создать новый Cargo

## СИНТАКСИС [#synopsis]

**create** \[**-n**\|**--namespace**\] \[**-v**\|**--volume**\] \[**-e**\|**--env**\]
\[**-h**\|**--help**\] \<*NAME*\> \<*IMAGE*\>

## ОПИСАНИЕ [#description]

Создать новый Cargo

## ПАРАМЕТРЫ [#options]

**-n**, **--namespace** *\<NAMESPACE\>*
Пространство имён нового Cargo; по умолчанию global

**-v**, **--volume** *\<VOLUMES\>*  
Тома Cargo

**-e**, **--env** *\<ENV\>*  
Переменные окружения Cargo

**-h**, **--help**  
Показать справку

\<*NAME*\>  
Имя Cargo

\<*IMAGE*\>  
Образ Cargo
