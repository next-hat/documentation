# Supprimer une ressource

# NOM

remove - Supprimer une ressource existante

## SYNOPSIS [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-h**\|**--help**\]
\[*KEYS*\]

## DESCRIPTION [#description]

Supprimer une ressource existante

## OPTIONS [#options]

**-y**, **--skip-confirm**  

**-h**, **--help**  
Afficher l’aide

\[*KEYS*\]  
Clés ou noms des objets à supprimer
