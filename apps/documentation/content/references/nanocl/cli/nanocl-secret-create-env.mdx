# Secret create env

# NAME

env - Create a new nanocl.io/env secret

## SYNOPSIS

**env** \[**-h**\|**--help**\] \<*VALUES*\>

## DESCRIPTION

Create a new nanocl.io/env secret

## OPTIONS

**-h**, **--help**  
Print help

\<*VALUES*\>  
List of values in the form of \`key=value\`
