# リソースの削除

# 名前

remove - 既存のリソースを削除します

## 書式 [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-h**\|**--help**\]
\[*KEYS*\]

## 説明 [#description]

既存のリソースを削除します

## オプション [#options]

**-y**, **--skip-confirm**  

**-h**, **--help**  
ヘルプを表示します

\[*KEYS*\]  
削除するオブジェクトのキーまたは名前
