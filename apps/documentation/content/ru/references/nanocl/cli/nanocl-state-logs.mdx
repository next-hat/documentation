# Журналы Statefile

# НАЗВАНИЕ

logs - Показать журналы элементов Statefile

## СИНТАКСИС [#synopsis]

**logs** \[**-s**\|**--source**\] \[**--since**\] \[**-u **\] \[**-t
**\] \[**--timestamps**\] \[**-f **\] \[**-h**\|**--help**\] \[*ARGS*\]

## ОПИСАНИЕ [#description]

Показать журналы элементов Statefile

## ПАРАМЕТРЫ [#options]

**-s**, **--source** *\<SOURCE\>*  
Путь или URL Statefile

**--since** *\<SINCE\>*  
Включать журналы начиная с метки времени Unix

**-u** *\<UNTIL\>*  
Включать журналы до метки времени Unix

**-t** *\<TAIL\>*  
Целое число возвращает последние n записей; "all" возвращает все записи

**--timestamps**  
Логический параметр: добавлять метку времени к каждой строке

**-f**  
Логический параметр: открыть журнал как поток

**-h**, **--help**  
Показать справку

\[*ARGS*\]  
Дополнительные аргументы для файла
