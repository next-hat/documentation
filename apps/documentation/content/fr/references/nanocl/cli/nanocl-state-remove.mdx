# Supprimer un Statefile

# NOM

remove - Supprimer les éléments d’un Statefile

## SYNOPSIS [#synopsis]

**remove** \[**-s**\|**--source**\] \[**-y**\|**--yes**\]
\[**-h**\|**--help**\] \[*ARGS*\]

## DESCRIPTION [#description]

Supprimer les éléments d’un Statefile

## OPTIONS [#options]

**-s**, **--source** *\<SOURCE\>*  
Chemin ou URL du Statefile

**-y**, **--yes**  
Ignorer la demande de confirmation

**-h**, **--help**  
Afficher l’aide

\[*ARGS*\]  
Arguments supplémentaires à transmettre au fichier
