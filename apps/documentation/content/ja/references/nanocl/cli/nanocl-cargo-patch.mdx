# Cargoの更新

# 名前

patch - 正規キーで Cargo を更新します

## 書式 [#synopsis]

**patch** \[**--container**\] \[**-i**\|**--image**\]
\[**-e**\|**--env**\] \[**-v**\|**--volume**\] \[**-h**\|**--help**\]
\<*KEY*\>

## 説明 [#description]

正規キーで Cargo を更新します

## オプション [#options]

**--container** *\<CONTAINER\>*
更新するアプリケーションコンテナの名前

**-i**, **--image** *\<IMAGE\>*  
Cargo の新しいイメージ

**-e**, **--env** *\<ENV\>*  
Cargo の新しい環境変数

**-v**, **--volume** *\<VOLUMES\>*  
Cargo の新しいボリューム

**-h**, **--help**  
ヘルプを表示します

\<*KEY*\>
更新する Cargo の正規キー
