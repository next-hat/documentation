# Cargo

# NOM

cargo - Gérer les Cargoes

## SYNOPSIS [#synopsis]

**cargo** \[**-h**\|**--help**\] \<*subcommands*\>

## DESCRIPTION [#description]

Gérer les Cargoes

## OPTIONS [#options]

**-h**, **--help**  
Afficher l’aide

# SOUS-COMMANDES

cargo-list(1)  
Lister les Cargoes existants

cargo-create(1)  
Créer un Cargo

cargo-start(1)  
Démarrer des Cargoes par leurs clés canoniques

cargo-stop(1)  
Arrêter des Cargoes par leurs clés canoniques

cargo-restart(1)  
Redémarrer des Cargoes par leurs clés canoniques

cargo-remove(1)  
Supprimer des Cargoes par leurs clés canoniques

cargo-inspect(1)  
Inspecter un Cargo par sa clé canonique

cargo-patch(1)  
Mettre à jour un Cargo par sa clé canonique

cargo-history(1)  
Consulter l’historique du Cargo

cargo-revert(1)  
Restaurer un Cargo à une entrée précise de l’historique

cargo-logs(1)  
Afficher les journaux

cargo-run(1)  
Exécuter un Cargo

cargo-stats(1)  
Afficher les statistiques du Cargo

cargo-help(1)  
Afficher ce message ou l’aide des sous-commandes indiquées
