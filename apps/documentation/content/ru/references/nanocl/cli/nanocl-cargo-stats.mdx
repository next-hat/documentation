# Статистика Cargo

# НАЗВАНИЕ

stats - Показать статистику Cargo

## СИНТАКСИС [#synopsis]

**stats** \[**--no-stream**\] \[**-h**\|**--help**\] \[*KEYS*\]

## ОПИСАНИЕ [#description]

Показать статистику Cargo

## ПАРАМЕТРЫ [#options]

**--no-stream**  
Отключить поток статистики и получить только первый результат

**-h**, **--help**  
Показать справку

\[*KEYS*\]
Канонические ключи Cargo для просмотра статистики
