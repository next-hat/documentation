# 状態

# 名前

state - Statefile を適用または削除します

## 書式 [#synopsis]

**state** \[**-h**\|**--help**\] \<*subcommands*\>

## 説明 [#description]

Statefile を適用または削除します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

# サブコマンド

state-man(1)  
Statefile のドキュメントを表示します

state-apply(1)  
Statefile の要素を作成または更新します

state-render(1)  
引数を使って Statefile をレンダリングし、ファイルに出力します

state-logs(1)  
Statefile の要素のログを表示します

state-remove(1)  
Statefile の要素を削除します

state-help(1)  
このメッセージ、または指定したサブコマンドのヘルプを表示します
