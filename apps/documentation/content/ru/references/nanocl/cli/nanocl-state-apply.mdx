# Применение Statefile

# НАЗВАНИЕ

apply - Создать или обновить элементы Statefile

## СИНТАКСИС [#synopsis]

**apply** \[**-s**\|**--source**\] \[**-f**\|**--follow**\]
\[**-y**\|**--yes**\] \[**-r**\|**--reload**\] \[**--remove-orphans**\]
\[**-h**\|**--help**\] \[*ARGS*\]

## ОПИСАНИЕ [#description]

Создать или обновить элементы Statefile

## ПАРАМЕТРЫ [#options]

**-s**, **--source** *\<SOURCE\>*  
Путь или URL Statefile

**-f**, **--follow**  
Следить за журналами развёрнутого Cargo

**-y**, **--yes**  
Пропустить запрос подтверждения

**-r**, **--reload**  
Выполнить применение даже без изменений состояния

**--remove-orphans**  
Удалить осиротевшие элементы

**-h**, **--help**  
Показать справку

\[*ARGS*\]  
Дополнительные аргументы для файла
