# 状態の削除

# 名前

remove - Statefile の要素を削除します

## 書式 [#synopsis]

**remove** \[**-s**\|**--source**\] \[**-y**\|**--yes**\]
\[**-h**\|**--help**\] \[*ARGS*\]

## 説明 [#description]

Statefile の要素を削除します

## オプション [#options]

**-s**, **--source** *\<SOURCE\>*  
Statefile のパスまたは URL

**-y**, **--yes**  
確認プロンプトを省略します

**-h**, **--help**  
ヘルプを表示します

\[*ARGS*\]  
ファイルに渡す追加の引数
