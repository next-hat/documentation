# 任务 移除

# 名称

remove - 按名称移除任务

## 语法 [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-h**\|**--help**\]
\[*KEYS*\]

## 说明 [#description]

按名称移除任务

## 选项 [#options]

**-y**, **--skip-confirm**  

**-h**, **--help**  
显示帮助

\[*KEYS*\]  
要移除的对象键或名称
