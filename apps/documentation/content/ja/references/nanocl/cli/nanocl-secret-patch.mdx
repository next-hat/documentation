# シークレットの更新

# 名前

patch - シークレットのデータを更新します

## 書式 [#synopsis]

**patch** \[**-h**\|**--help**\] \<*NAME*\> \<*subcommands*\>

## 説明 [#description]

シークレットのデータを更新します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

\<*NAME*\>  
更新するシークレットの名前

# サブコマンド

patch-env(1)  
環境変数シークレットの値を更新します

patch-tls(1)  
TLS シークレットの値を更新します

patch-container-registry(1)  
コンテナレジストリのシークレットの値を更新します

patch-help(1)  
このメッセージ、または指定したサブコマンドのヘルプを表示します
