# Signaux

# NOM

kill - Envoyer un signal à un processus

## SYNOPSIS [#synopsis]

**kill** \[**-s**\|**--signal**\] \[**-h**\|**--help**\]
\<*PROCESS*\>

## DESCRIPTION [#description]

Envoyer un signal à un processus

## OPTIONS [#options]

**-s**, **--signal** *\<SIGNAL\>* \[default: SIGKILL\]  
Signal à envoyer au processus

**-h**, **--help**  
Afficher l’aide

*\<PROCESS\>*  
Nom concret du processus ou identifiant Docker complet
