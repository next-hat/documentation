# 仮想マシン

# 名前

vm - 仮想マシンを管理します

## 書式 [#synopsis]

**vm** \[**-h**\|**--help**\] \<*subcommands*\>

## 説明 [#description]

仮想マシンを管理します

## オプション [#options]

**-h**, **--help**
ヘルプを表示します

# サブコマンド

vm-run(1)
仮想マシンを実行します

vm-create(1)
仮想マシンを作成します

vm-list(1)
仮想マシンを一覧表示します

vm-remove(1)
正規キーで仮想マシンを削除します

vm-inspect(1)
正規キーで仮想マシンの詳細を表示します

vm-start(1)
正規キーで仮想マシンを起動します

vm-stop(1)
正規キーで仮想マシンを停止します

vm-attach(1)
仮想マシンに接続します

vm-patch(1)
仮想マシンを更新します

vm-help(1)
このメッセージ、または指定したサブコマンドのヘルプを表示します
