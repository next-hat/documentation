# Ncproxy

# 名称

ncproxy

## 语法 [#synopsis]

**ncproxy** \[**--nginx-dir**\] \<**--state-dir**\>
\[**-h**\|**--help**\]

## 说明 [#description]

## 选项 [#options]

**--nginx-dir**=*NGINX_DIR* \[默认值： /etc/nginx\]  
Nginx 配置目录路径

**--state-dir**=*STATE_DIR*  
状态目录路径

**-h**, **--help**  
显示帮助
