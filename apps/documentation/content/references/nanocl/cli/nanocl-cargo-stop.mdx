# Cargo stop

# NAME

stop - Stop cargoes by canonical keys

## SYNOPSIS

**stop** \[**-h**\|**--help**\] \[*KEYS*\]

## DESCRIPTION

Stop cargoes by canonical keys

## OPTIONS

**-h**, **--help**  
Print help

\[*KEYS*\]
Canonical keys of the resources to stop
