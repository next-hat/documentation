# Statefile

Un Statefile décrit l’état souhaité d’un espace de noms.

Au format YAML, le déploiement du Cargo se résume ainsi :

<StatefileBlock example="get-started/deployment" />

Enregistrez ce fichier sous `my-cargo.yml` et appliquez-le avec :

```sh
nanocl state apply -s ./my-cargo.yml
```

Puis testez avec curl :

```sh
curl --header "Host: deploy-example.com" 127.0.0.1
```

Et voilà.
