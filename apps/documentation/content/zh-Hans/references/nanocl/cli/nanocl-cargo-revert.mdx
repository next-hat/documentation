# Cargo 恢复

# 名称

revert - 将 Cargo 恢复到指定历史版本

## 语法 [#synopsis]

**revert** \[**-h**\|**--help**\] \<*KEY*\> \<*HISTORY_ID*\>

## 说明 [#description]

将 Cargo 恢复到指定历史版本

## 选项 [#options]

**-h**, **--help**  
显示帮助

\<*KEY*\>
要恢复的 Cargo 规范键

\<*HISTORY_ID*\>  
恢复到指定历史版本
