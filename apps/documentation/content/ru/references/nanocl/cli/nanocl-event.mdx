# События

# НАЗВАНИЕ

event - Показать события или наблюдать за ними

## СИНТАКСИС [#synopsis]

**event** \[**-h**\|**--help**\] \<*subcommands*\>

## ОПИСАНИЕ [#description]

Показать события или наблюдать за ними

## ПАРАМЕТРЫ [#options]

**-h**, **--help**  
Показать справку

# ПОДКОМАНДЫ

event-list(1)  
Показать существующие события

event-watch(1)  
Наблюдать за новыми событиями в реальном времени

event-inspect(1)  
Просмотреть событие

event-help(1)  
Показать это сообщение или справку указанных подкоманд
