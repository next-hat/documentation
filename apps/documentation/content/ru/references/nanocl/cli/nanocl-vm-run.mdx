# Создание и запуск VM

# НАЗВАНИЕ

run - Запустить VM

## СИНТАКСИС [#synopsis]

**run** \[**-n**\|**--namespace**\] \[**--hostname**\] \[**--cpu**\] \[**--mem**\]
\[**--net-iface**\] \[**--user**\] \[**--password**\] \[**--ssh-key**\]
\[**--img-size**\] \[**--kvm**\] \[**-a**\|**--attach**\]
\[**-h**\|**--help**\] \<*NAME*\> \<*IMAGE*\>

## ОПИСАНИЕ [#description]

Запустить VM

## ПАРАМЕТРЫ [#options]

**-n**, **--namespace** *\<NAMESPACE\>*
Пространство имён новой VM; по умолчанию global

**--hostname** *\<HOSTNAME\>*
Имя хоста VM

**--cpu** *\<CPU\>*
Число CPU VM; по умолчанию 1

**--mem** *\<MEMORY\>*
Память VM в МБ; по умолчанию 512

**--net-iface** *\<NET_IFACE\>*
Сетевой интерфейс VM

**--user** *\<USER\>*
Пользователь VM по умолчанию

**--password** *\<PASSWORD\>*
Пароль VM по умолчанию

**--ssh-key** *\<SSH_KEY\>*
Ключ SSH пользователя

**--img-size** *\<IMAGE_SIZE\>*
Размер диска в ГБ

**--kvm**
Включить KVM

**-a**, **--attach**
Подключиться к VM

**-h**, **--help**
Показать справку

\<*NAME*\>
Имя VM

\<*IMAGE*\>
Полный путь образа VM
