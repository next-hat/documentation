# 仮想マシンの作成

# 名前

create - 仮想マシンを作成します

## 書式 [#synopsis]

**create** \[**-n**\|**--namespace**\] \[**--hostname**\] \[**--cpu**\] \[**--mem**\]
\[**--net-iface**\] \[**--user**\] \[**--password**\] \[**--ssh-key**\]
\[**--kvm**\] \[**-h**\|**--help**\] \<*NAME*\> \<*IMAGE*\>

## 説明 [#description]

仮想マシンを作成します

## オプション [#options]

**-n**, **--namespace** *\<NAMESPACE\>*
新しい仮想マシンの名前空間。デフォルトは global です

**--hostname** *\<HOSTNAME\>*
仮想マシンのホスト名

**--cpu** *\<CPU\>*
仮想マシンの CPU 数。デフォルトは 1 です

**--mem** *\<MEMORY\>*
仮想マシンのメモリー容量（MB）。デフォルトは 512 です

**--net-iface** *\<NET_IFACE\>*
仮想マシンのネットワークインターフェース

**--user** *\<USER\>*
仮想マシンのデフォルトのユーザー

**--password** *\<PASSWORD\>*
仮想マシンのデフォルトのパスワード

**--ssh-key** *\<SSH_KEY\>*
ユーザーの SSH キー

**--kvm**
KVM を有効にします

**-h**, **--help**
ヘルプを表示します

\<*NAME*\>
仮想マシンの名前

\<*IMAGE*\>
仮想マシンのイメージの絶対パス
