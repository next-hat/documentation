# Cargoの復元

# 名前

revert - Cargo を指定した履歴に戻します

## 書式 [#synopsis]

**revert** \[**-h**\|**--help**\] \<*KEY*\> \<*HISTORY_ID*\>

## 説明 [#description]

Cargo を指定した履歴に戻します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

\<*KEY*\>
元に戻す Cargo の正規キー

\<*HISTORY_ID*\>  
指定した履歴に戻します
