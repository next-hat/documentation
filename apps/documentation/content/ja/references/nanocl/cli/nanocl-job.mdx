# ジョブ

# 名前

job - ジョブを管理します

## 書式 [#synopsis]

**job** \[**-h**\|**--help**\] \<*subcommands*\>

## 説明 [#description]

ジョブを管理します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

# サブコマンド

job-list(1)  
既存のジョブを一覧表示します

job-remove(1)  
名前でジョブを削除します

job-inspect(1)  
名前でジョブの詳細を表示します

job-logs(1)  
ジョブのログを表示します

job-wait(1)  
ジョブの完了を待ちます

job-start(1)  
ジョブを開始します

job-help(1)  
このメッセージ、または指定したサブコマンドのヘルプを表示します
