# Supprimer un espace de noms

# NOM

remove - Supprimer un espace de noms

## SYNOPSIS [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-h**\|**--help**\]
\[*KEYS*\]

## DESCRIPTION [#description]

Supprimer un espace de noms

## OPTIONS [#options]

**-y**, **--skip-confirm**  

**-h**, **--help**  
Afficher l’aide

\[*KEYS*\]  
Clés ou noms des objets à supprimer
