# Processus

# NOM

ps - Afficher les processus

## SYNOPSIS [#synopsis]

**ps** \[**-q**\|**--quiet**\] \[**-l**\|**--limit**\]
\[**-o**\|**--offset**\] \[**--filters**\] \[**-n**\|**--namespace**\]
\[**-k**\|**--kind**\] \[**-a**\|**--all**\] \[**-h**\|**--help**\]

## DESCRIPTION [#description]

Afficher les processus

## OPTIONS [#options]

**-q**, **--quiet**  
Afficher uniquement les clés

**-l**, **--limit** *\<LIMIT\>*  
Limiter le nombre de résultats, 100 par défaut

**-o**, **--offset** *\<OFFSET\>*  
Décaler les résultats pour parcourir la liste

**--filters** *\<FILTERS\>*  
Filtres

**-n**, **--namespace** *\<NAMESPACE\>*  
Afficher tous les processus de l’espace de noms indiqué

**-k**, **--kind** *\<KIND\>*  
Afficher tous les processus du type indiqué

**-a**, **--all**  

**-h**, **--help**  
Afficher l’aide
