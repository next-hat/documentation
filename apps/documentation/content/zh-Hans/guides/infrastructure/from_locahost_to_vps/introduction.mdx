# 从 localhost 到 VPS

## 简介 [#introduction]

想将应用部署到 VPS 或专用物理服务器，却不知如何配置 Nginx？很多人也遇到相同问题。如何配置 Nginx 来部署应用，是 Stack Overflow 上的常见问题。只要有合适的指导，这个过程就能变得简单清晰。

本指南逐步介绍如何用 Docker 容器和 Nginx，将前端应用和 API 部署到 VPS。你将学会创建和配置容器、设置简单 Docker 网络，并用 Nginx 将域名流量转发到容器，还会学习通过 Certbot 的免费 SSL 证书保护部署。

无论刚接触 Docker 和 Nginx，还是已经熟悉它们，本指南都能提供构建可靠、安全基础设施需要的知识和工具。开始吧！
