# コンテキストのファイルから作成

# 名前

from - ファイルから新しいコンテキストを作成します

## 書式 [#synopsis]

**from** \[**-h**\|**--help**\] \<*PATH*\>

## 説明 [#description]

ファイルから新しいコンテキストを作成します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

\<*PATH*\>  
コンテキストファイルのパス
