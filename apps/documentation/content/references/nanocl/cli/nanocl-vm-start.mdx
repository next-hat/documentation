# Vm start

# NAME

start - Start VMs by canonical keys

## SYNOPSIS

**start** \[**-h**\|**--help**\] \[*KEYS*\]

## DESCRIPTION

Start VMs by canonical keys

## OPTIONS

**-h**, **--help**  
Print help

\[*KEYS*\]
Canonical keys of the resources to start
