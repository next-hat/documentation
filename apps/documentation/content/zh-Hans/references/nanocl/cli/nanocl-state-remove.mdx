# Statefile 移除

# 名称

remove - 移除 Statefile 中的对象

## 语法 [#synopsis]

**remove** \[**-s**\|**--source**\] \[**-y**\|**--yes**\]
\[**-h**\|**--help**\] \[*ARGS*\]

## 说明 [#description]

移除 Statefile 中的对象

## 选项 [#options]

**-s**, **--source** *\<SOURCE\>*  
Statefile 的路径或 URL

**-y**, **--yes**  
跳过确认提示

**-h**, **--help**  
显示帮助

\[*ARGS*\]  
传给文件的额外参数
