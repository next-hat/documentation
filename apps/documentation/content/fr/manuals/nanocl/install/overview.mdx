# Installer Nanocl

Cette page présente l’installation de Nanocl.<br/>

## Prérequis [#prerequisites]

Ses composants fonctionnent dans des conteneurs : un moteur de conteneurs est donc nécessaire.<br/>
Nanocl prend officiellement en charge [Docker][docker] et fonctionne également avec [Podman][podman].

### Docker [#docker]

Suivez le [guide officiel Docker][docker_install] pour votre système.<br/>
Sur Windows et macOS, utilisez [Docker Desktop][docker_desktop].

### Podman [#podman]

Podman fournissant une API compatible Docker, Nanocl peut aussi fonctionner avec lui.<br/>
Si vous préférez Podman, installez-le avec la [documentation officielle][podman_install].

## Plateformes prises en charge [#supported-platforms]

Seule la CLI ([nanocl][nanocl]) propose des binaires précompilés pour certaines plateformes :<br/>

- Linux: amd64
- macOS: aarch64 (Apple Silicon)
- Windows: amd64

Les autres plateformes et architectures peuvent compiler depuis les sources avec [crates.io][crates.io]. Consultez ses prérequis avant d’exécuter Cargo.

## Canaux de publication [#release-channels]

Nanocl propose deux canaux de mise à jour : **stable** et **nightly**.

* **Stable** : dernières versions destinées à une utilisation générale.
* **Nightly** : versions préliminaires pour tester les prochaines fonctionnalités.

<Callout type="warning" emoji="⚠️">

Les versions nightly sont expérimentales et peuvent contenir des changements incompatibles.

</Callout>
