# Historique de la ressource

# NOM

history - Consulter l’historique d’une ressource

## SYNOPSIS [#synopsis]

**history** \[**-h**\|**--help**\] \<*NAME*\>

## DESCRIPTION [#description]

Consulter l’historique d’une ressource

## OPTIONS [#options]

**-h**, **--help**  
Afficher l’aide

\<*NAME*\>  
Nom de la ressource dont consulter l’historique
