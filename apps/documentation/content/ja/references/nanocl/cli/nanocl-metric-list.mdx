# メトリクスの一覧

# 名前

list - 既存のメトリクスを一覧表示します

## 書式 [#synopsis]

**list** \[**-q**\|**--quiet**\] \[**-l**\|**--limit**\]
\[**-o**\|**--offset**\] \[**--filters**\] \[**-h**\|**--help**\]

## 説明 [#description]

既存のメトリクスを一覧表示します

## オプション [#options]

**-q**, **--quiet**  
キーだけを表示します

**-l**, **--limit** *\<LIMIT\>*  
結果の件数を制限します。デフォルトは 100 です

**-o**, **--offset** *\<OFFSET\>*  
結果を順に参照するためのオフセット

**--filters** *\<FILTERS\>*  
フィルター

**-h**, **--help**  
ヘルプを表示します
