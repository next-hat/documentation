# 名前空間

# 名前

namespace - 名前空間を管理します

## 書式 [#synopsis]

**namespace** \[**-h**\|**--help**\] \<*subcommands*\>

## 説明 [#description]

名前空間を管理します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

# サブコマンド

namespace-create(1)  
新しい名前空間を作成します

namespace-inspect(1)  
名前空間の詳細を表示します

namespace-remove(1)  
名前空間を削除します

namespace-list(1)  
既存の名前空間を一覧表示します

namespace-help(1)  
このメッセージ、または指定したサブコマンドのヘルプを表示します
