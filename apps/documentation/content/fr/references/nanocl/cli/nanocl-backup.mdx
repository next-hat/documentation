# Sauvegarde

# NOM

backup - Sauvegarder l’état courant

## SYNOPSIS [#synopsis]

**backup** \[**-o**\|**--output-dir**\] \[**-y**\|**--yes**\]
\[**-h**\|**--help**\]

## DESCRIPTION [#description]

Sauvegarder l’état courant

## OPTIONS [#options]

**-o**, **--output-dir** *\<OUTPUT_DIR\>*  
Répertoire de sauvegarde, par défaut le répertoire courant

**-y**, **--yes**  
Ignorer la confirmation

**-h**, **--help**  
Afficher l’aide
