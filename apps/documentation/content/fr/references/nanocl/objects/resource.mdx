# Resource

Dans Nanocl, une `Resource` représente un paramètre de configuration.<br />
Une `Resource` peut être tout `Kind` de configuration défini par l’utilisateur. Aucun `Kind` n’est actuellement pris en charge nativement :

Le `Kind` d’une `Resource` peut être défini par l’utilisateur, mais deux types sont généralement pris en charge après une installation de base :

| Kind du plugin    | Usage |
| ----------- | ----------- |
| ncproxy.io/rule | Données de configuration proxy installées par notre contrôleur proxy |
| ncdns.io/rule   | Données de configuration DNS installées par notre contrôleur DNS |

## Règle de proxy [#proxy-rule]

Une `ProxyRule` détermine comment accéder à vos `cargoes` via le proxy.<br />
Configurez les `ProxyRules` pour régler précisément leur accessibilité.

### Réseau de la règle de proxy [#proxy-rule-network]

| Réseau    | Usage |
| ----------- | ----------- |
| All | Écouter sur toutes les adresses réseau |
| Local | Écouter uniquement sur 127.0.0.1 |
| Public   | Écouter uniquement sur l’IP publique |
| Internal | Écouter sur la passerelle interne Nanocl |
