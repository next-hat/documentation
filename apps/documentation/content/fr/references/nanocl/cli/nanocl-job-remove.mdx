# Supprimer une tâche

# NOM

remove - Supprimer une tâche par son nom

## SYNOPSIS [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-h**\|**--help**\]
\[*KEYS*\]

## DESCRIPTION [#description]

Supprimer une tâche par son nom

## OPTIONS [#options]

**-y**, **--skip-confirm**  

**-h**, **--help**  
Afficher l’aide

\[*KEYS*\]  
Clés ou noms des objets à supprimer
