# 资源 检查

# 名称

inspect - 检查资源

## 语法 [#synopsis]

**inspect** \[**--display**\] \[**-h**\|**--help**\] \<*KEY*\>

## 说明 [#description]

检查资源

## 选项 [#options]

**--display** *\<DISPLAY\>*  
显示格式  

  
\[*可选值： *yaml, toml, json\]

**-h**, **--help**  
显示帮助

\<*KEY*\>  
要检查的对象键或名称
