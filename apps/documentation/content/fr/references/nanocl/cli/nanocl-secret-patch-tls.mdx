# Modifier un secret TLS

# NOM

tls - Mettre à jour les valeurs du secret TLS

## SYNOPSIS [#synopsis]

**tls** \[**--certificate**\] \[**--certificate-path**\]
\[**--certificate-key**\] \[**--certificate-key-path**\]
\[**--certificate-client**\] \[**--certificate-client-path**\]
\[**--dhparam**\] \[**--verify-client**\] \[**-h**\|**--help**\]

## DESCRIPTION [#description]

Mettre à jour les valeurs du secret TLS

## OPTIONS [#options]

**--certificate** *\<CERTIFICATE\>*  
Certificat

**--certificate-path** *\<CERTIFICATE_PATH\>*  
Chemin du certificat à lire depuis un fichier

**--certificate-key** *\<CERTIFICATE_KEY\>*  
Clé du certificat

**--certificate-key-path** *\<CERTIFICATE_KEY_PATH\>*  
Chemin de la clé du certificat à lire depuis un fichier

**--certificate-client** *\<CERTIFICATE_CLIENT\>*  
Certificat client

**--certificate-client-path** *\<CERTIFICATE_CLIENT_PATH\>*  
Chemin du certificat client à lire depuis un fichier

**--dhparam** *\<DHPARAM\>*  
DHParam

**--verify-client**  
Vérifier le client

**-h**, **--help**  
Afficher l’aide
