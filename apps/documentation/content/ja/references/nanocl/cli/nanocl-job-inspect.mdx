# ジョブの詳細表示

# 名前

inspect - 名前でジョブの詳細を表示します

## 書式 [#synopsis]

**inspect** \[**--display**\] \[**-h**\|**--help**\] \<*KEY*\>

## 説明 [#description]

名前でジョブの詳細を表示します

## オプション [#options]

**--display** *\<DISPLAY\>*  
表示形式  

  
\[*指定可能な値: *yaml, toml, json\]

**-h**, **--help**  
ヘルプを表示します

\<*KEY*\>  
詳細を表示するオブジェクトのキーまたは名前
