# Cargo 更新

# 名称

patch - 按规范键更新 Cargo

## 语法 [#synopsis]

**patch** \[**--container**\] \[**-i**\|**--image**\]
\[**-e**\|**--env**\] \[**-v**\|**--volume**\] \[**-h**\|**--help**\]
\<*KEY*\>

## 说明 [#description]

按规范键更新 Cargo

## 选项 [#options]

**--container** *\<CONTAINER\>*
要更新的应用容器名称

**-i**, **--image** *\<IMAGE\>*  
Cargo 的新镜像

**-e**, **--env** *\<ENV\>*  
Cargo 的新环境变量

**-v**, **--volume** *\<VOLUMES\>*  
Cargo 的新卷

**-h**, **--help**  
显示帮助

\<*KEY*\>
要更新的 Cargo 规范键
