# Cargo

# 名前

cargo - Cargo を管理します

## 書式 [#synopsis]

**cargo** \[**-h**\|**--help**\] \<*subcommands*\>

## 説明 [#description]

Cargo を管理します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

# サブコマンド

cargo-list(1)  
既存の Cargo を一覧表示します

cargo-create(1)  
新しい Cargo を作成します

cargo-start(1)  
正規キーで Cargo を起動します

cargo-stop(1)  
正規キーで Cargo を停止します

cargo-restart(1)  
正規キーで Cargo を再起動します

cargo-remove(1)  
正規キーで Cargo を削除します

cargo-inspect(1)  
正規キーで Cargo の詳細を表示します

cargo-patch(1)  
正規キーで Cargo を更新します

cargo-history(1)  
Cargo の履歴を一覧表示します

cargo-revert(1)  
Cargo を指定した履歴に戻します

cargo-logs(1)  
ログを表示します

cargo-run(1)  
Cargo を実行します

cargo-stats(1)  
Cargo の統計情報を表示します

cargo-help(1)  
このメッセージ、または指定したサブコマンドのヘルプを表示します
