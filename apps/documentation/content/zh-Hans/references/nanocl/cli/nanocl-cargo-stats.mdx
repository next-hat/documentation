# Cargo 统计

# 名称

stats - 显示 Cargo 统计信息

## 语法 [#synopsis]

**stats** \[**--no-stream**\] \[**-h**\|**--help**\] \[*KEYS*\]

## 说明 [#description]

显示 Cargo 统计信息

## 选项 [#options]

**--no-stream**  
禁用统计流，仅获取第一条结果

**-h**, **--help**  
显示帮助

\[*KEYS*\]
要显示统计信息的 Cargo 规范键
