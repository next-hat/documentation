# 仮想マシンの削除

# 名前

remove - 正規キーで仮想マシンを削除します

## 書式 [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-h**\|**--help**\]
\[*KEYS*\]

## 説明 [#description]

正規キーで仮想マシンを削除します

## オプション [#options]

**-y**, **--skip-confirm**  

**-h**, **--help**  
ヘルプを表示します

\[*KEYS*\]  
削除するオブジェクトのキーまたは名前
