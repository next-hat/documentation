# Statefile 手册

# 名称

man - 显示 Statefile 文档

## 语法 [#synopsis]

**man** \<**-s**\|**--source**\> \[**-h**\|**--help**\]

## 说明 [#description]

显示 Statefile 文档

## 选项 [#options]

**-s**, **--source** *\<SOURCE\>*

**-h**, **--help**  
显示帮助
