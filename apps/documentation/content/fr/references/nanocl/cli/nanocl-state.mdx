# Statefile

# NOM

state - Appliquer ou supprimer un Statefile

## SYNOPSIS [#synopsis]

**state** \[**-h**\|**--help**\] \<*subcommands*\>

## DESCRIPTION [#description]

Appliquer ou supprimer un Statefile

## OPTIONS [#options]

**-h**, **--help**  
Afficher l’aide

# SOUS-COMMANDES

state-man(1)  
Afficher la documentation d’un Statefile

state-apply(1)  
Créer ou mettre à jour les éléments d’un Statefile

state-render(1)  
Produire un Statefile avec ses arguments dans un fichier de sortie

state-logs(1)  
Afficher les journaux des éléments d’un Statefile

state-remove(1)  
Supprimer les éléments d’un Statefile

state-help(1)  
Afficher ce message ou l’aide des sous-commandes indiquées
