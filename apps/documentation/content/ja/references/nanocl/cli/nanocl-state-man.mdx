# 状態のマニュアル

# 名前

man - Statefile のドキュメントを表示します

## 書式 [#synopsis]

**man** \<**-s**\|**--source**\> \[**-h**\|**--help**\]

## 説明 [#description]

Statefile のドキュメントを表示します

## オプション [#options]

**-s**, **--source** *\<SOURCE\>*  
Statefile のパスまたは URL

**-h**, **--help**  
ヘルプを表示します
