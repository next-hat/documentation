# Создание и запуск Cargo

# НАЗВАНИЕ

run - Запустить Cargo

## СИНТАКСИС [#synopsis]

**run** \[**-n**\|**--namespace**\] \[**-v**\|**--volume**\] \[**-e**\|**--env**\]
\[**-h**\|**--help**\] \<*NAME*\> \<*IMAGE*\> \[*COMMAND*\]

## ОПИСАНИЕ [#description]

Запустить Cargo

## ПАРАМЕТРЫ [#options]

**-n**, **--namespace** *\<NAMESPACE\>*
Пространство имён нового Cargo; по умолчанию global

**-v**, **--volume** *\<VOLUMES\>*  
Тома Cargo

**-e**, **--env** *\<ENV\>*  
Переменные окружения Cargo

**-h**, **--help**  
Показать справку

\<*NAME*\>  
Имя Cargo

\<*IMAGE*\>  
Образ Cargo

\[*COMMAND*\]  
Выполняемая команда
