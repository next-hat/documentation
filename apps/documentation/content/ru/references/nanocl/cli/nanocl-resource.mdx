# Ресурсы

# НАЗВАНИЕ

resource - Управлять ресурсами

## СИНТАКСИС [#synopsis]

**resource** \[**-h**\|**--help**\] \<*subcommands*\>

## ОПИСАНИЕ [#description]

Управлять ресурсами

## ПАРАМЕТРЫ [#options]

**-h**, **--help**  
Показать справку

# ПОДКОМАНДЫ

resource-remove(1)  
Удалить существующий ресурс

resource-list(1)  
Показать существующие пространства имён

resource-inspect(1)  
Просмотреть ресурс

resource-history(1)  
Просмотреть историю ресурса

resource-revert(1)  
Вернуть ресурс к выбранному состоянию истории

resource-help(1)  
Показать это сообщение или справку указанных подкоманд
