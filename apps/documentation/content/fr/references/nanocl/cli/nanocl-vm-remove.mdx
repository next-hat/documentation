# Supprimer une VM

# NOM

remove - Supprimer des VM par leurs clés canoniques

## SYNOPSIS [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-h**\|**--help**\]
\[*KEYS*\]

## DESCRIPTION [#description]

Supprimer des VM par leurs clés canoniques

## OPTIONS [#options]

**-y**, **--skip-confirm**  

**-h**, **--help**  
Afficher l’aide

\[*KEYS*\]  
Clés ou noms des objets à supprimer
