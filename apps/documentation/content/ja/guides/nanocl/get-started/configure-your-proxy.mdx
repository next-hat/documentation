# プロキシの設定

`proxy controller` を使って `proxy rules` を作成し、Cargo を公開できます。<br/>
`proxy rule` は、特定の IP アドレス、ポート、ドメイン名へのアクセスを Cargo のアップストリームに転送します。

## プロキシルールを追加する [#add-proxy-rules]

<Callout type="info">

このチュートリアルを進めるには、my-cargo という Cargo が稼働し、ポート **9001** が HTTP 用に開いている必要があります。

</Callout>

`proxy.deploy-example.yml` というファイルを作成し、次の内容をコピーします。

<StatefileBlock example="get-started/proxy" />

次のコマンドでプロキシルールを作成します。

```sh
nanocl state apply -s proxy.deploy-example.yml
```

既存のリソースは次のコマンドで確認できます。

```sh
nanocl resource ls
```

プロキシルールが動作するか確認しましょう。

```sh
curl --header "Host: deploy-example.com" 127.0.0.1
```

次の内容が出力されます。

```json
{
  "headers": {
    "x-forwarded-proto": "http",
    "x-forwarded-for": "127.0.0.1",
    "accept": "*/*",

    "connection": "close",
    "x-forwarded-scheme": "http",
    "host": "deploy-example.com",
    "user-agent": "curl/8.2.1"
  },
```
