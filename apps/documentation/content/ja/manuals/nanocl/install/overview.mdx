# Nanocl のインストール

このページでは、Nanocl のインストール方法の概要を説明します。<br/>

## 前提条件 [#prerequisites]

Nanocl のコンポーネントはコンテナ内で実行されるため、コンテナエンジンが必要です。<br/>
Nanocl は [Docker][docker] を公式にサポートし、[Podman][podman] でも動作します。

### Docker [#docker]

お使いのシステムに対応する [Docker の公式インストールガイド][docker_install]に従ってください。<br/>
Windows と macOS では [Docker Desktop][docker_desktop] を使います。

### Podman [#podman]

Podman は Docker 互換の API を提供するため、Nanocl は Podman でも動作します。<br/>
Podman を使いたい場合は、[公式ドキュメント][podman_install]に従ってインストールしてください。

## 対応プラットフォーム [#supported-platforms]

CLI（[nanocl][nanocl]）のみ、次の一部のプラットフォーム向けにビルド済みのバイナリーを提供しています。<br/>

- Linux: amd64
- macOS: aarch64 (Apple Silicon)
- Windows: amd64

その他のプラットフォームやアーキテクチャでは、[crates.io][crates.io] 経由でソースからインストールできます。Cargo を実行する前に、そのページの前提条件を確認してください。

## リリースチャンネル [#release-channels]

Nanocl には **stable** と **nightly** の 2 つの更新チャンネルがあります。

* **Stable**: 一般利用向けの最新リリース。
* **Nightly**: 今後の機能を試すためのプレリリースビルド。

<Callout type="warning" emoji="⚠️">

Nightly ビルドは実験的なもので、互換性のない変更が含まれる場合があります。

</Callout>
