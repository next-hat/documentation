# シグナル送信

# 名前

kill - プロセスにシグナルを送信します

## 書式 [#synopsis]

**kill** \[**-s**\|**--signal**\] \[**-h**\|**--help**\]
\<*PROCESS*\>

## 説明 [#description]

プロセスにシグナルを送信します

## オプション [#options]

**-s**, **--signal** *\<SIGNAL\>* \[デフォルト: SIGKILL\]  
プロセスに送信するシグナル

**-h**, **--help**  
ヘルプを表示します

*\<PROCESS\>*  
実際のプロセス名または完全な Docker ID
