# Cargo start

# NAME

start - Start cargoes by canonical keys

## SYNOPSIS

**start** \[**-h**\|**--help**\] \[*KEYS*\]

## DESCRIPTION

Start cargoes by canonical keys

## OPTIONS

**-h**, **--help**  
Print help

\[*KEYS*\]
Canonical keys of the resources to start
