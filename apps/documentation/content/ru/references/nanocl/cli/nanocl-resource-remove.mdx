# Удаление ресурса

# НАЗВАНИЕ

remove - Удалить существующий ресурс

## СИНТАКСИС [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-h**\|**--help**\]
\[*KEYS*\]

## ОПИСАНИЕ [#description]

Удалить существующий ресурс

## ПАРАМЕТРЫ [#options]

**-y**, **--skip-confirm**  

**-h**, **--help**  
Показать справку

\[*KEYS*\]  
Ключи или имена удаляемых объектов
