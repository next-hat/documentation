# Inspection

# NOM

inspect - Inspecter un processus

## SYNOPSIS [#synopsis]

**inspect** \[**--display**\] \[**-h**\|**--help**\] \<*KEY*\>

## DESCRIPTION [#description]

Inspecter un processus

## OPTIONS [#options]

**--display** *\<DISPLAY\>*  
Format d’affichage  

  
\[*valeurs possibles : *yaml, toml, json\]

**-h**, **--help**  
Afficher l’aide

\<*KEY*\>  
Clé ou nom de l’objet à inspecter
