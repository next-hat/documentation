# 実行

# 名前

exec - プロセス内でコマンドを実行します

## 書式 [#synopsis]

**exec** \[**-d**\|**--detach**\] \[**--detach-keys**\]
\[**-e**\|**--env**\] \[**--env-file**\]
\[**-i**\|**--interactive**\] \[**--privileged**\]
\[**-t**\|**--tty**\] \[**-u**\|**--user**\]
\[**-w**\|**--workdir**\] \[**-h**\|**--help**\]
\<*PROCESS*\> \<*COMMAND*\>...

## 説明 [#description]

プロセス内でコマンドを実行します

## オプション [#options]

**-d**, **--detach**  
コマンドをバックグラウンドで実行します

**--detach-keys** *\<DETACH_KEYS\>*  
対話的な exec から切断するキー操作を変更します

**-e**, **--env** *\<ENV\>*  
環境変数を設定します

**--env-file** *\<ENV_FILE\>*  
ファイルから環境変数を読み込みます

**-i**, **--interactive**  
標準入力を開いたままにします

**--privileged**  
コマンドに追加の権限を付与します

**-t**, **--tty**  
疑似 TTY を割り当てます

**-u**, **--user** *\<USER\>*  
コマンドのユーザーと任意のグループ

**-w**, **--workdir** *\<WORKDIR\>*  
プロセス内の作業ディレクトリ

**-h**, **--help**  
ヘルプを表示します

*\<PROCESS\>*  
実際のプロセス名または完全な Docker ID

*\<COMMAND\>*...  
実行するコマンドと引数
