# リソースの復元

# 名前

revert - リソースを指定した履歴に戻します

## 書式 [#synopsis]

**revert** \[**-h**\|**--help**\] \<*NAME*\> \<*KEY*\>

## 説明 [#description]

リソースを指定した履歴に戻します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

\<*NAME*\>  
元に戻すリソースの名前

\<*KEY*\>  
戻す履歴のキー
