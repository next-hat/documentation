# 仮想マシンの一覧

# 名前

list - 仮想マシンを一覧表示します

## 書式 [#synopsis]

**list** \[**-n**\|**--namespace**\] \[**-q**\|**--quiet**\] \[**-l**\|**--limit**\]
\[**-o**\|**--offset**\] \[**--filters**\] \[**-h**\|**--help**\]

## 説明 [#description]

仮想マシンを一覧表示します

## オプション [#options]

**-n**, **--namespace** *\<NAMESPACE\>*
任意の名前空間フィルター。省略するとすべての名前空間のリソースを返します

**-q**, **--quiet**  
キーだけを表示します

**-l**, **--limit** *\<LIMIT\>*  
結果の件数を制限します。デフォルトは 100 です

**-o**, **--offset** *\<OFFSET\>*  
結果を順に参照するためのオフセット

**--filters** *\<FILTERS\>*  
フィルター

**-h**, **--help**  
ヘルプを表示します
