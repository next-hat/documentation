# VM 检查

# 名称

inspect - 按规范键检查 VM

## 语法 [#synopsis]

**inspect** \[**--display**\] \[**-h**\|**--help**\] \<*KEY*\>

## 说明 [#description]

按规范键检查 VM

## 选项 [#options]

**--display** *\<DISPLAY\>*  
显示格式  

  
\[*可选值： *yaml, toml, json\]

**-h**, **--help**  
显示帮助

\<*KEY*\>  
要检查的对象规范键
