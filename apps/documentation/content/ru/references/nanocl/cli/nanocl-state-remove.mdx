# Удаление Statefile

# НАЗВАНИЕ

remove - Удалить элементы Statefile

## СИНТАКСИС [#synopsis]

**remove** \[**-s**\|**--source**\] \[**-y**\|**--yes**\]
\[**-h**\|**--help**\] \[*ARGS*\]

## ОПИСАНИЕ [#description]

Удалить элементы Statefile

## ПАРАМЕТРЫ [#options]

**-s**, **--source** *\<SOURCE\>*  
Путь или URL Statefile

**-y**, **--yes**  
Пропустить запрос подтверждения

**-h**, **--help**  
Показать справку

\[*ARGS*\]  
Дополнительные аргументы для файла
