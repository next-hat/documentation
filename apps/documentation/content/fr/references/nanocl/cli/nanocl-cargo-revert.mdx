# Restaurer un Cargo

# NOM

revert - Restaurer un Cargo à une entrée précise de l’historique

## SYNOPSIS [#synopsis]

**revert** \[**-h**\|**--help**\] \<*KEY*\> \<*HISTORY_ID*\>

## DESCRIPTION [#description]

Restaurer un Cargo à une entrée précise de l’historique

## OPTIONS [#options]

**-h**, **--help**  
Afficher l’aide

\<*KEY*\>
Clé canonique du Cargo à restaurer

\<*HISTORY_ID*\>  
Restaurer une entrée précise de l’historique
