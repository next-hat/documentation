# Nanocl

# 名称

nanocl - 容器和虚拟机编排工具

## 语法 [#synopsis]

**nanocl** \[**-H**\|**--host**\] \[**-h**\|**--help**\]
\[**-V**\|**--version**\] \<*subcommands*\>

## 说明 [#description]

Nanocl 是现代、独立的容器和虚拟机编排工具。声明式 Statefile（YAML/TOML/JSON）以及明确、可预测的默认值，提供清晰的开发到生产流程。采用 Rust 构建以保证性能和安全，在保持强大功能与扩展性的同时降低运维开销。通过动态路由、DNS 和端到端 TLS，管理 Cargo、资源、任务和 VM。从本地单节点开始，准备好后再扩展；易于学习，面向生产。

## 选项 [#options]

**-H**, **--host** *\<HOST\>*  
Nanocld 主机默认值：unix://run/nanocl/nanocl.sock

**-h**, **--help**  
显示帮助（-h 显示摘要）

**-V**, **--version**  
显示版本
