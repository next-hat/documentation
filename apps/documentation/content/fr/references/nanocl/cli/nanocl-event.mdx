# Événements

# NOM

event - Afficher ou surveiller les événements

## SYNOPSIS [#synopsis]

**event** \[**-h**\|**--help**\] \<*subcommands*\>

## DESCRIPTION [#description]

Afficher ou surveiller les événements

## OPTIONS [#options]

**-h**, **--help**  
Afficher l’aide

# SOUS-COMMANDES

event-list(1)  
Lister les événements existants

event-watch(1)  
Surveiller les nouveaux événements en temps réel

event-inspect(1)  
Inspecter un événement précis

event-help(1)  
Afficher ce message ou l’aide des sous-commandes indiquées
