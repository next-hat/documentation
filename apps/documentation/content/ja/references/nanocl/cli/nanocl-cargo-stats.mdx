# Cargoの統計情報

# 名前

stats - Cargo の統計情報を表示します

## 書式 [#synopsis]

**stats** \[**--no-stream**\] \[**-h**\|**--help**\] \[*KEYS*\]

## 説明 [#description]

Cargo の統計情報を表示します

## オプション [#options]

**--no-stream**  
統計情報のストリーミングを無効にし、最初の結果だけを取得します

**-h**, **--help**  
ヘルプを表示します

\[*KEYS*\]
統計情報を表示する Cargo の正規キー
