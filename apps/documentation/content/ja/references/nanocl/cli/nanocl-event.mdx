# イベント

# 名前

event - イベントを表示または監視します

## 書式 [#synopsis]

**event** \[**-h**\|**--help**\] \<*subcommands*\>

## 説明 [#description]

イベントを表示または監視します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

# サブコマンド

event-list(1)  
既存のイベントを一覧表示します

event-watch(1)  
新しいイベントをリアルタイムで監視します

event-inspect(1)  
指定したイベントの詳細を表示します

event-help(1)  
このメッセージ、または指定したサブコマンドのヘルプを表示します
