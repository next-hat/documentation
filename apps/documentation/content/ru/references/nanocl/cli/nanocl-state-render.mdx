# Формирование Statefile

# НАЗВАНИЕ

render - Сформировать Statefile с аргументами в выходной файл

## СИНТАКСИС [#synopsis]

**render** \[**-s**\|**--source**\] \[**-o**\|**--output**\]
\[**-y**\|**--yes**\] \[**-h**\|**--help**\] \[*ARGS*\]

## ОПИСАНИЕ [#description]

Сформировать Statefile с аргументами в выходной файл

## ПАРАМЕТРЫ [#options]

**-s**, **--source** *\<SOURCE\>*  
Путь или URL Statefile

**-o**, **--output** *\<OUTPUT\>*  
Путь выходного файла Statefile

**-y**, **--yes**  
Пропустить запрос подтверждения

**-h**, **--help**  
Показать справку

\[*ARGS*\]  
Дополнительные аргументы для файла
