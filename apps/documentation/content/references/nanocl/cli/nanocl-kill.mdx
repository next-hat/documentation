# Kill

# NAME

kill - Send a signal to a process

## SYNOPSIS

**kill** \[**-s**\|**--signal**\] \[**-h**\|**--help**\]
\<*PROCESS*\>

## DESCRIPTION

Send a signal to a process

## OPTIONS

**-s**, **--signal** *\<SIGNAL\>* \[default: SIGKILL\]  
Signal to send to the process

**-h**, **--help**  
Print help

*\<PROCESS\>*  
Concrete process name or full Docker ID
