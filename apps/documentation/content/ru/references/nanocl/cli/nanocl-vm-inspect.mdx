# Просмотр VM

# НАЗВАНИЕ

inspect - Просмотреть VM по каноническому ключу

## СИНТАКСИС [#synopsis]

**inspect** \[**--display**\] \[**-h**\|**--help**\] \<*KEY*\>

## ОПИСАНИЕ [#description]

Просмотреть VM по каноническому ключу

## ПАРАМЕТРЫ [#options]

**--display** *\<DISPLAY\>*  
Формат вывода  

  
\[*допустимые значения: *yaml, toml, json\]

**-h**, **--help**  
Показать справку

\<*KEY*\>  
Канонический ключ просматриваемого объекта
