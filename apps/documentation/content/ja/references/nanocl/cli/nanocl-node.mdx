# ノード

# 名前

node - ノードを管理します（実験的機能）

## 書式 [#synopsis]

**node** \[**-h**\|**--help**\] \<*subcommands*\>

## 説明 [#description]

ノードを管理します（実験的機能）

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

# サブコマンド

node-list(1)  
ノードを一覧表示します

node-help(1)  
このメッセージ、または指定したサブコマンドのヘルプを表示します
