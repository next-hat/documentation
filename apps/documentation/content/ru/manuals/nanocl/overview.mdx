# Обзор Nanocl

Nanocl — открытая платформа управления нагрузками.
Она работает как клиент-серверное приложение с компонентами:

* Сервер с длительно работающим демоном [nanocld](/ru/references/nanocl/daemon/overview).
* API с интерфейсами для взаимодействия программ с демоном Nanocl.
* CLI [nanocl](/ru/references/nanocl/cli/overview), взаимодействующий с демоном.

CLI использует API Nanocl для управления демоном через скрипты и прямые команды. Другие приложения Nanocl также используют API и CLI. Демон создаёт объекты Nanocl и управляет ими: образами, заданиями, Cargo и виртуальными машинами.

Nanocl 0.18 главным образом работает на одном узле. Демон предоставляет экспериментальные API узлов, но выпуск не включает автоматическое планирование на нескольких узлах, автомасштабирование и высокую доступность всего кластера. Nanocl использует [metrs](https://github.com/next-hat/metrs) для метрик хоста.

Подробнее — в [Архитектуре Nanocl](/ru/guides/nanocl/overview#nanocl-architecture).
