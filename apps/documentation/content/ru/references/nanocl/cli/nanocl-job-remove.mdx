# Удаление задания

# НАЗВАНИЕ

remove - Удалить задание по имени

## СИНТАКСИС [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-h**\|**--help**\]
\[*KEYS*\]

## ОПИСАНИЕ [#description]

Удалить задание по имени

## ПАРАМЕТРЫ [#options]

**-y**, **--skip-confirm**  

**-h**, **--help**  
Показать справку

\[*KEYS*\]  
Ключи или имена удаляемых объектов
