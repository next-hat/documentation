# ジョブの待機

# 名前

wait - ジョブの完了を待ちます

## 書式 [#synopsis]

**wait** \[**-c **\] \[**-h**\|**--help**\] \<*NAME*\>

## 説明 [#description]

ジョブの完了を待ちます

## オプション [#options]

**-c** *\<CONDITION\>*  
待機する状態

**-h**, **--help**  
ヘルプを表示します

\<*NAME*\>  
完了を待つジョブの名前
