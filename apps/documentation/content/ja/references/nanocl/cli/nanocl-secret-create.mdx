# シークレットの作成

# 名前

create - 新しいシークレットを作成します

## 書式 [#synopsis]

**create** \[**-h**\|**--help**\] \<*NAME*\> \<*subcommands*\>

## 説明 [#description]

新しいシークレットを作成します

## オプション [#options]

**-h**, **--help**  
ヘルプを表示します

\<*NAME*\>  
シークレットの名前

# サブコマンド

create-env(1)  
新しい nanocl.io/env シークレットを作成します

create-tls(1)  
新しい nanocl.io/tls シークレットを作成します

create-container-registry(1)  
新しい nanocl.io/container-registry シークレットを作成します

create-help(1)  
このメッセージ、または指定したサブコマンドのヘルプを表示します
