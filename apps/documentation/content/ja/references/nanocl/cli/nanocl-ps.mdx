# プロセス一覧

# 名前

ps - プロセスを表示します

## 書式 [#synopsis]

**ps** \[**-q**\|**--quiet**\] \[**-l**\|**--limit**\]
\[**-o**\|**--offset**\] \[**--filters**\] \[**-n**\|**--namespace**\]
\[**-k**\|**--kind**\] \[**-a**\|**--all**\] \[**-h**\|**--help**\]

## 説明 [#description]

プロセスを表示します

## オプション [#options]

**-q**, **--quiet**  
キーだけを表示します

**-l**, **--limit** *\<LIMIT\>*  
結果の件数を制限します。デフォルトは 100 です

**-o**, **--offset** *\<OFFSET\>*  
結果を順に参照するためのオフセット

**--filters** *\<FILTERS\>*  
フィルター

**-n**, **--namespace** *\<NAMESPACE\>*  
指定した名前空間のすべてのプロセスを表示します

**-k**, **--kind** *\<KIND\>*  
指定した種類のすべてのプロセスを表示します

**-a**, **--all**  

**-h**, **--help**  
ヘルプを表示します
