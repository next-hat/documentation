# 状態のレンダリング

# 名前

render - 引数を使って Statefile をレンダリングし、ファイルに出力します

## 書式 [#synopsis]

**render** \[**-s**\|**--source**\] \[**-o**\|**--output**\]
\[**-y**\|**--yes**\] \[**-h**\|**--help**\] \[*ARGS*\]

## 説明 [#description]

引数を使って Statefile をレンダリングし、ファイルに出力します

## オプション [#options]

**-s**, **--source** *\<SOURCE\>*  
Statefile のパスまたは URL

**-o**, **--output** *\<OUTPUT\>*  
レンダリングした Statefile の出力先パス

**-y**, **--yes**  
確認プロンプトを省略します

**-h**, **--help**  
ヘルプを表示します

\[*ARGS*\]  
ファイルに渡す追加の引数
