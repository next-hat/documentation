# 命名空间 移除

# 名称

remove - 移除命名空间

## 语法 [#synopsis]

**remove** \[**-y**\|**--skip-confirm**\] \[**-h**\|**--help**\]
\[*KEYS*\]

## 说明 [#description]

移除命名空间

## 选项 [#options]

**-y**, **--skip-confirm**  

**-h**, **--help**  
显示帮助

\[*KEYS*\]  
要移除的对象键或名称
