# Cargoの実行

# 名前

run - Cargo を実行します

## 書式 [#synopsis]

**run** \[**-n**\|**--namespace**\] \[**-v**\|**--volume**\] \[**-e**\|**--env**\]
\[**-h**\|**--help**\] \<*NAME*\> \<*IMAGE*\> \[*COMMAND*\]

## 説明 [#description]

Cargo を実行します

## オプション [#options]

**-n**, **--namespace** *\<NAMESPACE\>*
新しい Cargo の名前空間。デフォルトは global です

**-v**, **--volume** *\<VOLUMES\>*  
Cargo のボリューム

**-e**, **--env** *\<ENV\>*  
Cargo の環境変数

**-h**, **--help**  
ヘルプを表示します

\<*NAME*\>  
Cargo の名前

\<*IMAGE*\>  
Cargo のイメージ

\[*COMMAND*\]  
実行するコマンド
