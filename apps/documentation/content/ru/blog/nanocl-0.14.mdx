В быстро развивающейся сфере оркестрации контейнеров и виртуальных машин (VM) необходимо постоянно внедрять новые решения и отвечать на потребности разработчиков и операторов. Представляем Nanocl 0.14 — новую версию нашего оркестратора с множеством улучшений и возможностей для упрощения развёртывания.

{/*truncate*/}

Рассмотрим изменения и дополнения во всех наших компонентах:

## Nanocld [#nanocld]

### Изменено [#changed]

- **Новая система событий**: улучшенная обработка событий для наблюдения за развёртываниями и управления ими.
- **Управление образами**: с `ImagePullPolicy` можно всегда скачивать образы или делать это только при их отсутствии; `ImagePullSecrets` позволяет скачивать образы из частных реестров.
- **Обработка процессов**: фоновая загрузка образов, очереди задач для обработки объектов и наблюдение за состоянием их процессов.

### Исправлено [#fixed]

- **Репликация**: устранены проблемы репликации для надёжного и плавного масштабирования.

## Nanocl [#nanocl]

### Изменено [#changed-1]

- **Управление секретами**: новые команды `nanocl secret create` создают секреты без Statefile.
- **Контексты**: изменение конечной точки по умолчанию упрощает интеграцию с разными средами.
Подробнее — в руководстве по [контекстам][contexts].
- **SubStates**: подключайте другие Statefile к своей конфигурации, упрощая сложные развёртывания.
Подробнее — в руководстве по [вложенным состояниям][substates].

### Исправлено [#fixed-1]

**Журналирование**: исправлены проблемы журналов состояния заданий, чтобы лучше отслеживать операции развёртывания.

## Ncproxy [#ncproxy]

### Изменено [#changed-2]

- **Обработка событий**: новая система событий демона повышает надёжность и производительность.

### Добавлено [#added]

- **Контроль доступа**: `AllowedIps` задаёт IP-адреса, которым разрешён доступ к опубликованным сервисам, повышая безопасность и контроль сети.

### Исправлено [#fixed-2]

- **Поддержка протоколов**: исправлены проблемы TCP через SSL и добавлена возможность задавать пути целей для HTTP.

Nanocl 0.14 устраняет существующие проблемы и добавляет возможности для эффективного масштабирования и управления инфраструктурой. Версия подходит для оркестрации контейнеров, управления VM и защиты сетевого доступа с учётом ваших меняющихся потребностей.

Обновитесь по [руководству][upgrading] и познакомьтесь с возможностями Nanocl 0.14. Следите за следующими обновлениями: мы продолжаем развивать автоматизацию развёртывания.
