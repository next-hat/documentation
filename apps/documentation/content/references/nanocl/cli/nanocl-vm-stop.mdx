# Vm stop

# NAME

stop - Stop VMs by canonical keys

## SYNOPSIS

**stop** \[**-h**\|**--help**\] \[*KEYS*\]

## DESCRIPTION

Stop VMs by canonical keys

## OPTIONS

**-h**, **--help**  
Print help

\[*KEYS*\]
Canonical keys of the resources to stop
