# Откат Cargo

# НАЗВАНИЕ

revert - Вернуть Cargo к выбранному состоянию истории

## СИНТАКСИС [#synopsis]

**revert** \[**-h**\|**--help**\] \<*KEY*\> \<*HISTORY_ID*\>

## ОПИСАНИЕ [#description]

Вернуть Cargo к выбранному состоянию истории

## ПАРАМЕТРЫ [#options]

**-h**, **--help**  
Показать справку

\<*KEY*\>
Канонический ключ Cargo для отката

\<*HISTORY_ID*\>  
Вернуться к выбранному состоянию истории
