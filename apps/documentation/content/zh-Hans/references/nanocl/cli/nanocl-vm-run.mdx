# VM 运行

# 名称

run - 运行 VM

## 语法 [#synopsis]

**run** \[**-n**\|**--namespace**\] \[**--hostname**\] \[**--cpu**\] \[**--mem**\]
\[**--net-iface**\] \[**--user**\] \[**--password**\] \[**--ssh-key**\]
\[**--img-size**\] \[**--kvm**\] \[**-a**\|**--attach**\]
\[**-h**\|**--help**\] \<*NAME*\> \<*IMAGE*\>

## 说明 [#description]

运行 VM

## 选项 [#options]

**-n**, **--namespace** *\<NAMESPACE\>*
新 VM 的命名空间，默认为 global

**--hostname** *\<HOSTNAME\>*
VM 主机名

**--cpu** *\<CPU\>*
VM 的 CPU 数量，默认为 1

**--mem** *\<MEMORY\>*
VM 内存，单位 MB，默认为 512

**--net-iface** *\<NET_IFACE\>*
VM 网络接口

**--user** *\<USER\>*
VM 默认用户

**--password** *\<PASSWORD\>*
VM 默认密码

**--ssh-key** *\<SSH_KEY\>*
用户 SSH 密钥

**--img-size** *\<IMAGE_SIZE\>*
磁盘大小，单位 GB

**--kvm**
启用 KVM

**-a**, **--attach**
连接 VM

**-h**, **--help**
显示帮助

\<*NAME*\>
VM 名称

\<*IMAGE*\>
VM 镜像完整路径
