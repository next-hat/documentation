# Cargoの作成

# 名前

create - 新しい Cargo を作成します

## 書式 [#synopsis]

**create** \[**-n**\|**--namespace**\] \[**-v**\|**--volume**\] \[**-e**\|**--env**\]
\[**-h**\|**--help**\] \<*NAME*\> \<*IMAGE*\>

## 説明 [#description]

新しい Cargo を作成します

## オプション [#options]

**-n**, **--namespace** *\<NAMESPACE\>*
新しい Cargo の名前空間。デフォルトは global です

**-v**, **--volume** *\<VOLUMES\>*  
Cargo のボリューム

**-e**, **--env** *\<ENV\>*  
Cargo の環境変数

**-h**, **--help**  
ヘルプを表示します

\<*NAME*\>  
Cargo の名前

\<*IMAGE*\>  
Cargo のイメージ
