# Exécuter un Cargo

# NOM

run - Exécuter un Cargo

## SYNOPSIS [#synopsis]

**run** \[**-n**\|**--namespace**\] \[**-v**\|**--volume**\] \[**-e**\|**--env**\]
\[**-h**\|**--help**\] \<*NAME*\> \<*IMAGE*\> \[*COMMAND*\]

## DESCRIPTION [#description]

Exécuter un Cargo

## OPTIONS [#options]

**-n**, **--namespace** *\<NAMESPACE\>*
Espace de noms du nouveau Cargo ; global par défaut

**-v**, **--volume** *\<VOLUMES\>*  
Volumes du Cargo

**-e**, **--env** *\<ENV\>*  
Variables d’environnement du Cargo

**-h**, **--help**  
Afficher l’aide

\<*NAME*\>  
Nom du Cargo

\<*IMAGE*\>  
Image du Cargo

\[*COMMAND*\]  
Commande à exécuter
