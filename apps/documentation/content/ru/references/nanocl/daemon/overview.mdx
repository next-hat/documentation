# Демон Nanocl

`nanocld` управляет локальным узлом Docker, хранит желаемое и наблюдаемое состояние и предоставляет API Nanocl. Подключение узлов в 0.18 экспериментально; оно не означает автоматическое планирование на нескольких узлах или высокую доступность.

```sh
nanocld [OPTIONS]
```

| Параметр | Назначение |
| --- | --- |
| `-H, --hosts HOSTS` | Адреса API; установленное значение по умолчанию `unix:///run/nanocl.sock` |
| `--docker-host DOCKER_HOST` | Конечная точка Docker daemon; по умолчанию `unix:///var/run/docker.sock` |
| `--store-addr STORE_ADDR` | Адрес подключения CockroachDB |
| `--state-dir STATE_DIR` | Каталог состояния выполнения; по умолчанию `/var/lib/nanocl` |
| `--conf-dir CONF_DIR` | Каталог конфигурации; по умолчанию `/etc/nanocl` |
| `--gateway GATEWAY` | Шлюз хоста; определяется автоматически, если не указан |
| `--hostname HOSTNAME` | Имя узла; определяется автоматически, если не указано |
| `--node NODES` | Экспериментальные конечные точки для подключения к узлам |
| `--advertise-addr ADDRESS` | Адрес, объявляемый другим узлам |
| `--gid GID` | ID группы сокета Unix; по умолчанию `0` |
| `--cert`, `--cert-key`, `--cert-ca` | Необязательные материалы TLS API |
| `--verify`, `--password` | Необязательные настройки проверки TLS API и пароля |

Точный синтаксис установленной сборки покажет `nanocld --help`. API 0.18 доступен в боковой панели или на [странице OpenAPI этой версии](/ru/references/nanocl/daemon/v0.18).
