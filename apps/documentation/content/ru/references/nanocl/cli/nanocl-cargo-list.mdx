# Список Cargo

# НАЗВАНИЕ

list - Показать существующие Cargo

## СИНТАКСИС [#synopsis]

**list** \[**-n**\|**--namespace**\] \[**-q**\|**--quiet**\] \[**-l**\|**--limit**\]
\[**-o**\|**--offset**\] \[**--filters**\] \[**-h**\|**--help**\]

## ОПИСАНИЕ [#description]

Показать существующие Cargo

## ПАРАМЕТРЫ [#options]

**-n**, **--namespace** *\<NAMESPACE\>*
Необязательный фильтр пространства имён; без него возвращаются ресурсы всех пространств имён

**-q**, **--quiet**  
Показывать только ключи

**-l**, **--limit** *\<LIMIT\>*  
Ограничить число результатов; по умолчанию 100

**-o**, **--offset** *\<OFFSET\>*  
Смещение для перехода между результатами

**--filters** *\<FILTERS\>*  
Filters

**-h**, **--help**  
Показать справку
