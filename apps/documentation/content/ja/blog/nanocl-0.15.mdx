**Nanocl 0.15.0** を公開しました。コンテナのオーケストレーションと仮想化の管理を効率化する新機能、大幅な改善、重要な修正を含みます。**2024 年 6 月 11 日**公開のこのリリースで加わったツールと改善を、詳しく見ていきましょう。

{/* truncate */}

## 主な変更点 [#key-highlights]

### 新機能 [#new-features]

1. **コマンド出力の改善：**
   - `cargo ls`、`vm ls`、`job ls` コマンドの表に状態情報が表示され、リソースの状態をすぐに把握できます。

2. **詳細な情報の確認：**
   - 特定のメトリクスやイベントの詳細を取得する `nanocl metric inspect` と `nanocl event inspect` コマンドを追加しました。

3. **状態のバックアップ：**
   - 新しい `nanocl backup` コマンドで、現在の状態を複数の Statefile にバックアップできます。設定を安全に保存し、復元できるようになります。

4. **環境変数による上書き：**
   - `HOST` 環境変数でデフォルトのホストを上書きできます。
   - クライアント操作で使う証明書とキーを、`CERT` と `CERT_KEY` 環境変数で渡せます。

5. **孤立したオブジェクトの削除：**
   - `nanocl state apply --remove-orphans` オプションで孤立したオブジェクトを削除し、環境を整理できます。

6. **TLS シークレットの作成：**
   - `nanocl secret create tls` が証明書とキーのパスを受け取れるようになり、TLS シークレットの作成が簡単になりました。

7. **man ページの生成：**
   - すべてのコマンドに man ページが用意されました。[こちら][manpages]で Markdown 形式のページを参照するか、たとえば `man nanocl-cargo-create` を実行してください。

### 不具合の修正 [#bug-fixes]

- **コマンドの信頼性の向上：**
  - `nanocl cargo run`、`nanocl vm run`、`nanocl cargo start`、`nanocl cargo stop`、`nanocl cargo patch`、`nanocl job start`、`nanocl vm start`、`nanocl vm stop` などのコマンドが、対応する操作の完了を正しく待ってから終了するようになりました。

- **正確な状態の比較：**
  - Statefile の適用時に差分を判定する処理が、現在の状態と新しい状態を正確に比較するようになり、一貫性が向上しました。

### 変更 [#changes]

- **インターフェースの統一：**
  - `inspect`、`rm`、`stop`、`start` などのコマンドを共通のインターフェースに整理し、すべてのオブジェクトを同じ感覚で操作できるようにしました。

- **出力の簡素化：**
  - `cargo ls` と `vm ls` の表から名前空間の列を削除し、出力を見やすくしました。

- **進行状況表示の改善：**
  - Statefile の適用と削除の進行状況表示を整理し、処理を分かりやすくしました。

# Nanocld 0.15.0

**2024 年 5 月 16 日**公開の Nanocld 0.15.0 では、依存関係の更新、エンドポイントとオプションの追加、重要な問題の修正を行いました。

### 主な改善 [#key-enhancements]

- **コマンドラインの改善：**
  - コマンドラインからストアのアドレスを指定する `--store-addr` オプションを追加しました。

- **新しいエンドポイント：**
  - メトリクスとイベントの詳細情報を取得する `GET /metrics/{key}/inspect` と `GET /event/{key}/inspect` を追加しました。

- **リポジトリとフィルターの改善：**
  - 汎用的な `RepositoryCountBy` インターフェースを追加し、SQL フィルターの仕組みを改善して、パフォーマンスと柔軟性を向上しました。
  - すべての SQL スキーマにインデックスを追加して、クエリのパフォーマンスを向上しました。
  - 日付でクエリを絞り込めるようになりました。

### 不具合の修正 [#bug-fixes-1]

- **ジョブ管理：**
  - ジョブを削除する前にプロセスを停止し、正しく後処理を行うようにしました。
  - Cargo の更新と再起動に関する問題を修正しました。

### 変更 [#changes-1]

- **リソースの詳細取得パス：**
  - 一貫性を保つため、リソースの詳細取得パスを `GET /resources/{name}/inspect` に変更しました。

# Ncproxy 0.12.0

Nanocld と同じ **2024 年 5 月 16 日**に公開した Ncproxy 0.12.0 では、依存関係を更新し、セキュリティを強化するリクエスト制限を追加しました。

### 主な更新 [#key-updates]

- **依存関係の更新：**
  - ntex バージョン 2 に更新しました。

- **リクエスト制限：**
  - 不正利用を防ぐため、HTTP のリクエスト制限ゾーンを追加しました。

### 変更 [#changes-2]

- **HTTPS の処理：**
  - HTTPS へのリダイレクトを削除し、セキュリティを高める HSTS（HTTP Strict Transport Security）を利用するようにしました。
