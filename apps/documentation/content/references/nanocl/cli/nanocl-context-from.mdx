# Context from

# NAME

from - Create a new context from a file

## SYNOPSIS

**from** \[**-h**\|**--help**\] \<*PATH*\>

## DESCRIPTION

Create a new context from a file

## OPTIONS

**-h**, **--help**  
Print help

\<*PATH*\>  
Path to context file
