# Statefile 渲染

# 名称

render - 使用参数渲染 Statefile 并写入输出文件

## 语法 [#synopsis]

**render** \[**-s**\|**--source**\] \[**-o**\|**--output**\]
\[**-y**\|**--yes**\] \[**-h**\|**--help**\] \[*ARGS*\]

## 说明 [#description]

使用参数渲染 Statefile 并写入输出文件

## 选项 [#options]

**-s**, **--source** *\<SOURCE\>*  
Statefile 的路径或 URL

**-o**, **--output** *\<OUTPUT\>*  
渲染后的 Statefile 输出路径

**-y**, **--yes**  
跳过确认提示

**-h**, **--help**  
显示帮助

\[*ARGS*\]  
传给文件的额外参数
