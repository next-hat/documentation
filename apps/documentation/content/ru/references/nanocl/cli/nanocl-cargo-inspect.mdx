# Просмотр Cargo

# НАЗВАНИЕ

inspect - Просмотреть Cargo по каноническому ключу

## СИНТАКСИС [#synopsis]

**inspect** \[**--display**\] \[**-h**\|**--help**\] \<*KEY*\>

## ОПИСАНИЕ [#description]

Просмотреть Cargo по каноническому ключу

## ПАРАМЕТРЫ [#options]

**--display** *\<DISPLAY\>*  
Формат вывода  

  
\[*допустимые значения: *yaml, toml, json\]

**-h**, **--help**  
Показать справку

\<*KEY*\>  
Канонический ключ просматриваемого объекта
